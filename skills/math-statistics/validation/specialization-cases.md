## statistical_model

- **spec:** Theta a single point: the model is fully specified, no inference to do
- **spec:** Theta = all laws on X: the fully nonparametric model
- **spec:** Theta a subset of R^d: a parametric model (next node)
- **drop `none_all_hypotheses_essential`:** every listed hypothesis is used; see the block above

## parametric_model

- **spec:** d = 1: a scalar parameter (Bernoulli p, Poisson lambda, exponential rate)
- **spec:** d = 2: N(mu, sigma^2), Gamma(shape, rate), the simple linear model's (slope, intercept) with sigma^2 known
- **spec:** Theta open: needed for the interior-point regularity condition later
- **drop `finite_fixed_dimension`:** a location model with an unknown error density f is nonparametric in f; the CRLB and MLE-normality theory below does not apply to f without extra structure

## parameter_space

- **spec:** Theta = (0, inf) for a variance or a rate
- **spec:** Theta = [0, 1] for a probability -- note the boundary points, where interior-point regularity fails
- **spec:** Theta = R^d for a location / regression-coefficient vector
- **spec:** Theta = { positive definite d x d matrices } for a covariance parameter
- **drop `admissibility_of_the_constraint`:** if the true p is 0 or 1 (on the boundary of [0,1]) the MLE is still consistent but sqrt(n)-asymptotic normality fails -- the limit is one-sided

## identifiability

- **spec:** a full-rank exponential family in its natural parametrization is identifiable
- **spec:** N(mu, sigma^2) is identifiable in (mu, sigma^2); it is NOT identifiable in (mu, sigma) vs (mu, -sigma) if sigma is allowed negative
- **spec:** a two-component mixture is identifiable only up to permutation of the labels ('label switching')
- **drop `identifiability`:** the model X ~ N(alpha + beta, 1) with theta = (alpha, beta): alpha and beta are not separately identifiable -- only their sum is. The MLE of (alpha, beta) is not consistent (it wanders along the ridge alpha + beta = const); the Fisher information matrix is singular. This is exactly why fisher_information_positive_definite is a separate hypothesis.

## dominated_family

- **spec:** discrete model: mu = counting measure, f = the pmf
- **spec:** continuous model on R^k: mu = Lebesgue, f = the pdf
- **spec:** a mixed discrete-continuous model: mu = Lebesgue + counting on the atoms
- **drop `dominated_family`:** Theta = R, P_theta = the point mass delta_theta. No single sigma-finite mu dominates all of them (an uncountable family of mutually singular measures). The likelihood is not well defined and the whole density-based apparatus (score, Fisher information, factorization) is unavailable.

## iid_sample

- **spec:** n = 1: a single observation; the likelihood is f(x_1; theta)
- **spec:** the joint density is prod_{i=1}^n f(x_i; theta) -- the product structure is what makes the log-likelihood a SUM
- **spec:** non-iid extensions (regression with fixed covariates, time series) replace the product by the actual joint density
- **drop `independence`:** if the X_i are positively correlated, the effective sample size is below n; a variance estimate treating them as independent is too small and confidence intervals undercover
- **drop `identical_distribution`:** if each X_i has its own theta_i there is nothing to estimate without a link; the model is not a fixed-d parametric model

## statistic

- **spec:** the sample mean, sample variance, order statistics, the maximum -- all statistics
- **spec:** the sample itself, X = (X_1,...,X_n), is the trivial (always sufficient) statistic
- **spec:** a constant map is a (useless, always ancillary) statistic
- **drop `no_theta_dependence`:** sum_i (X_i - mu_0)^2 with a KNOWN mu_0 is a statistic; sum_i (X_i - mu)^2 with the unknown true mu is NOT a statistic -- it cannot be computed

## likelihood_function

- **spec:** n iid Bernoulli(p): L(p) = p^{sum x_i} (1-p)^{n - sum x_i}
- **spec:** n iid N(mu, sigma^2): L(mu, sigma^2) = (2 pi sigma^2)^{-n/2} exp(- sum (x_i - mu)^2 / 2 sigma^2)
- **spec:** uniform(0, theta): L(theta) = theta^{-n} 1{ theta >= max x_i } -- not differentiable at the MLE
- **drop `dominated_family`:** without a common dominating measure the products f(x_i; theta) for different theta are not comparable and 'maximize the likelihood' is meaningless

## log_likelihood

- **spec:** Bernoulli: ell(p) = (sum x_i) log p + (n - sum x_i) log(1 - p)
- **spec:** the maximizer of ell is the maximizer of L (log is increasing) -- this is why one always works with ell
- **spec:** at a data point with f(x_i; theta) = 0, ell(theta) = -inf: theta is excluded
- **drop `none_all_hypotheses_essential`:** every listed hypothesis is used; see the block above

## score_function

- **spec:** Bernoulli: U(p) = (sum x_i)/p - (n - sum x_i)/(1 - p); setting U(p) = 0 gives p_hat = xbar
- **spec:** N(mu, sigma^2 known): U(mu) = sum (x_i - mu)/sigma^2; root at mu_hat = xbar
- **spec:** exponential family f = h exp(eta T - A): U(eta) = sum T(x_i) - n A'(eta) -- the score is 'observed minus expected sufficient statistic'
- **drop `log_likelihood_smooth`:** uniform(0, theta): ell(theta) = -n log theta on theta >= max x_i, so U(theta) = -n/theta is never 0 -- the MLE is at the boundary theta_hat = max x_i and the score equation has no solution. Score-based asymptotics (Fisher information, mle_asymptotic_normality) do not apply.

## fisher_information

- **spec:** Bernoulli(p): I(p) = 1 / (p(1-p)) -- largest near p = 0 or 1, smallest at p = 1/2
- **spec:** Poisson(lambda): I(lambda) = 1/lambda
- **spec:** N(mu, sigma^2): I(mu) = 1/sigma^2 (with sigma^2 known); the information about mu does not depend on mu
- **spec:** location family f(x - theta): I(theta) = int (f'/f)^2 f dx does not depend on theta
- **drop `interchange_derivative_integral`:** if int f can't be differentiated under the integral sign, E[U_1] != 0 and I(theta) = Var(U_1) != E[U_1^2]; the CRLB denominator and the information equality both fail
- **drop `log_likelihood_smooth`:** uniform(0, theta): the naive I(theta) = 1/theta^2 gives the WRONG rate -- the MLE converges at rate n, not sqrt(n), so 'Var >= 1/(n I)' is not the operative bound

## fisher_information_matrix

- **spec:** N(mu, sigma^2), theta = (mu, sigma^2): I = diag(1/sigma^2, 1/(2 sigma^4)) -- mu and sigma^2 are 'information-orthogonal'
- **spec:** a full-rank exponential family: I(eta) = Hess A(eta), the Hessian of the cumulant function (always PD on the interior)
- **spec:** block structure: a zero off-diagonal block means the blocks' MLEs are asymptotically independent
- **drop `fisher_information_positive_definite`:** the non-identified model N(alpha + beta, 1): I(alpha, beta) = [[1,1],[1,1]], singular -- not invertible, so I^{-1} does not exist and MLE-normality fails along the ridge

## score_identity

- **spec:** Bernoulli: E_p[(X - p)/(p(1-p))] = 0 since E[X] = p
- **spec:** N(mu, sigma^2 known): E_mu[(X - mu)/sigma^2] = 0
- **spec:** gives the moment condition behind method-of-moments and estimating-equation estimators
- **drop `support_independent_of_theta`:** uniform(0, theta): the support {0 <= x <= theta} moves with theta, so d/dtheta int_0^theta theta^{-1} dx has a boundary term; E_theta[U(theta)] = -1/theta != 0. The score is biased and every downstream result (CRLB, information equality) fails.
- **drop `interchange_derivative_integral`:** a family where the tails are too heavy for the dominated-derivative condition: the swap of d/dtheta and int is invalid and E[U] can be nonzero

## information_equality

- **spec:** Bernoulli: -E[d^2/dp^2 ell_1] = -E[-X/p^2 - (1-X)/(1-p)^2] = 1/(p(1-p)) = Var((X-p)/(p(1-p)))
- **spec:** exponential family: both sides equal A''(eta) -- the cumulant function's curvature
- **spec:** lets you estimate I(theta) either by the sample variance of the scores or by the negative average Hessian (the latter is what optimizers return for free)
- **drop `interchange_derivative_integral`:** same failure as score_identity: without the second interchange the two formulas disagree and the 'sandwich' variance A^{-1} B A^{-1} (with A != B) is the correct one -- this is exactly the misspecification-robust case
- **drop `log_likelihood_smooth`:** a non-twice-differentiable log-density (Laplace / double-exponential at its median) -- the second-derivative form does not exist though the variance form may

## support_independent_of_theta

- **spec:** N(mu, sigma^2): support is all of R for every (mu, sigma^2) -- holds
- **spec:** Poisson(lambda): support is {0,1,2,...} for every lambda -- holds
- **spec:** exponential(rate): support (0, inf) for every rate -- holds
- **drop `support_independent_of_theta`:** uniform(0, theta): support (0, theta) depends on theta. Consequences: the score identity fails, the CRLB does not bind (the MLE max X_i beats it), the MLE converges at rate n and its limit is Exponential-not-Normal. The whole 'regular' theory is replaced by 'non-regular' (boundary) theory.
- **drop `also fails for`:** shifted exponential f(x; theta) = e^{-(x - theta)} 1{x >= theta}; and for uniform(theta, theta + 1)

## interchange_derivative_integral

- **spec:** exponential families on their natural parameter's interior: holds automatically (analyticity of A)
- **spec:** N, Poisson, Gamma, Beta in their standard parametrizations: holds
- **spec:** the sufficient condition (ra_interchange_limit_integral): a local integrable envelope for the theta-derivative
- **drop `interchange_derivative_integral`:** combine with a moving support (uniform(0, theta)) or heavy tails and the swap introduces a boundary term or diverges: E[score] != 0, so score_identity, information_equality, cramer_rao_lower_bound all fail. The robust replacement is the sandwich variance.

## true_parameter_interior

- **spec:** theta_0 = 1/2 for a Bernoulli p in (0,1): interior, holds
- **spec:** theta_0 on the boundary: p = 0, a variance component = 0, a correlation = 1
- **drop `true_parameter_interior`:** testing H0: sigma^2_between = 0 in a random-effects model -- the null is on the boundary of [0, inf). The LRT statistic -2 log Lambda is NOT chi^2_1 under H0; it is a 50:50 mixture of chi^2_0 and chi^2_1 (Self-Liang / Chernoff). Using the chi^2_1 critical value makes the test conservative.
- **drop `also`:** p_hat for a truly-degenerate coin (p = 0): sqrt(n)(p_hat - 0) does not converge to a two-sided normal

## fisher_information_positive_definite

- **spec:** any full-rank exponential family on the interior: I(eta) = Hess A(eta) is PD (A strictly convex)
- **spec:** N(mu, sigma^2): I = diag(1/sigma^2, 1/(2 sigma^4)) PD for every sigma^2 > 0
- **drop `fisher_information_positive_definite`:** the non-identified N(alpha + beta, 1): I = [[1,1],[1,1]] has eigenvalue 0 along (1, -1). The MLE is not consistent for (alpha, beta) and I^{-1} does not exist. This hypothesis is the local (2nd-order) counterpart of the global identifiability hypothesis.
- **drop `singular in the limit`:** a model at a parameter where a component's information -> 0 (e.g. a mixture weight at 0 or 1): near-singular I, unstable inversion, wide/unreliable intervals

## log_likelihood_smooth

- **spec:** exponential families: log f = eta.T(x) - A(eta) + log h(x) is real-analytic in eta -- holds on the interior
- **spec:** N, Gamma, Beta, Poisson in standard parametrizations: hold
- **spec:** weaker 'differentiability in quadratic mean' (van der Vaart) replaces C^3 for the modern proof of mle_asymptotic_normality -- but C^3 is what the classical proof and this capsule use
- **drop `log_likelihood_smooth`:** Laplace(theta) = (1/2) e^{-|x - theta|}: log f = -|x - theta| + const is not differentiable at x = theta. The MLE is the sample median; it IS sqrt(n)-asymptotically normal (variance 1), but via a different argument (the score is a sum of sign(X_i - theta), not a smooth function) -- the C^3 route does not apply.
- **drop `uniform(0, theta)`:** not differentiable in theta at all on the relevant set -- non-regular, rate n not sqrt(n)

## exponential_family

- **spec:** Bernoulli(p): eta = log(p/(1-p)), T(x) = x, A(eta) = log(1 + e^eta), h = 1
- **spec:** N(mu, sigma^2): eta = (mu/sigma^2, -1/(2 sigma^2)), T(x) = (x, x^2) -- a 2-parameter family
- **spec:** Poisson, exponential, gamma, beta, binomial(n fixed), multinomial, chi-squared -- all exponential families
- **spec:** uniform(0, theta), Cauchy, Student's t (df unknown) -- NOT exponential families (support moves / no finite-dim sufficient statistic)
- **drop `finite_k`:** the location-scale Cauchy family has no sufficient statistic of dimension < n (Pitman-Koopman-Darmois: among families with fixed support, exactly the exponential families admit a fixed-dimension sufficient statistic). All the clean exp-family results below then fail.

## natural_parameter_space

- **spec:** Bernoulli: H = R (all eta give a finite sum)
- **spec:** N(mu, sigma^2): H = R x (-inf, 0) -- the second natural parameter must be negative
- **spec:** gamma(shape a, rate b), a known: H = (-inf, 0) in the rate's natural parameter -eta
- **drop `eta_in_interior`:** at a boundary point of H (if the family is defined there) A may be finite but not differentiable, or E[T] infinite -- the moment identities and PD information fail. 'Full-rank' results need int(H).

## cumulant_function

- **spec:** Bernoulli: A(eta) = log(1 + e^eta); A'(eta) = e^eta/(1+e^eta) = p; A''(eta) = p(1-p)
- **spec:** N(mu, sigma^2), eta_1 = mu/sigma^2: partial in eta_1 recovers mu
- **spec:** Poisson: A(eta) = e^eta = lambda; A' = A'' = lambda (mean = variance)
- **drop `none_all_hypotheses_essential`:** every listed hypothesis is used; see the block above

## mean_value_parametrization

- **spec:** Bernoulli: mu = p (the natural sufficient statistic's mean); eta = logit(p)
- **spec:** N: mu = (E X, E X^2); the moment parametrization
- **spec:** the MLE in the mean parametrization is simply mu_hat = Tbar = (1/n) sum T(x_i) -- always unbiased for mu
- **drop `none_all_hypotheses_essential`:** every listed hypothesis is used; see the block above

## exponential_family_moment_identities

- **spec:** Bernoulli: A'(eta) = p (mean of T = X), A''(eta) = p(1-p) (variance)
- **spec:** the score U(eta) = sum_i T(x_i) - n grad A(eta) = 'observed minus expected sufficient statistic' -- zero exactly at the MLE
- **spec:** gives the information equality for free: I(eta) = Var(U_1) = Hess A(eta) = -E[Hess log f]
- **drop `natural_parameter_space`:** at a boundary eta the interchange of d/deta and int fails; grad A need not equal E[T] (which may be infinite)

## exponential_family_sufficient_statistic

- **spec:** Bernoulli: sum X_i (the count) is sufficient -- the individual outcomes are not needed
- **spec:** N(mu, sigma^2): (sum X_i, sum X_i^2), equivalently (Xbar, S^2), is sufficient
- **spec:** Poisson: sum X_i; exponential: sum X_i; gamma(a known, rate): sum X_i
- **drop `exponential_family`:** outside exponential families the minimal sufficient statistic generally has dimension growing with n -- e.g. for iid Cauchy or uniform-location the full order statistic is minimal sufficient. Pitman-Koopman-Darmois makes this an iff (fixed support).

## exponential_family_completeness

- **spec:** N(mu, sigma^2) full family: (sum X_i, sum X_i^2) is complete -- hence (Xbar, S^2) is, so any unbiased function of it is UMVUE (Lehmann-Scheffe)
- **spec:** Bernoulli, Poisson, exponential: sum X_i is complete
- **spec:** used to get Xbar _||_ S^2 for a normal sample via Basu
- **drop `full_rank`:** the CURVED family N(theta, theta^2) (one parameter, T two-dimensional constrained to a parabola): the sufficient statistic is NOT complete -- there exist nonzero unbiased-of-zero functions. UMVUE claims via Lehmann-Scheffe then do not go through.
- **drop `H_open`:** N(mu, sigma^2) with sigma^2 KNOWN and mu restricted to integers: H is not open, sum X_i is sufficient but not complete

## sufficiency

- **spec:** Bernoulli: the count sum X_i is sufficient; the order of the 0s and 1s is not informative
- **spec:** N(mu, sigma^2): (Xbar, S^2) is sufficient
- **spec:** uniform(0, theta): the maximum X_(n) is sufficient
- **drop `conditional_law_theta_free`:** Xbar alone is NOT sufficient for (mu, sigma^2) in a normal sample: given Xbar, the spread of the residuals still depends on sigma^2. Discarding S^2 loses information about sigma^2.

## neyman_fisher_factorization

- **spec:** Bernoulli: f = p^{sum x_i}(1-p)^{n - sum x_i} = [p/(1-p)]^{sum x_i} (1-p)^n . 1  => T = sum x_i sufficient
- **spec:** N(mu, sigma^2): the exponent expands to a function of (sum x_i, sum x_i^2) plus a theta-free term
- **spec:** uniform(0, theta): f = theta^{-n} 1{x_(n) <= theta} . 1{x_(1) >= 0}  => T = x_(n) sufficient
- **drop `dominated_family`:** for a family of mutually singular laws there is no common density to factor; sufficiency must be checked directly from the conditional law

## minimal_sufficiency

- **spec:** exponential family (minimal representation): sum_i T(X_i) is minimal sufficient
- **spec:** iid Cauchy(theta, 1): the full order statistic is minimal sufficient -- no finite-dimensional reduction
- **spec:** uniform(theta, theta+1): (X_(1), X_(n)) is minimal sufficient, 2-dimensional for a 1-dim parameter
- **drop `minimality`:** sum_i T(X_i) for a CURVED exponential family: still minimal sufficient but its dimension exceeds dim(theta) -- 'minimal' does not mean 'dimension = dim theta'

## ancillary_statistic

- **spec:** location family f(x - theta): the residuals (X_i - Xbar), or the range X_(n) - X_(1), are ancillary
- **spec:** N(mu, 1): S^2 is ancillary for mu
- **spec:** the sample size n itself, if random but theta-free, is ancillary
- **drop `theta_free_law`:** S^2 is NOT ancillary for sigma^2 in N(mu, sigma^2) -- its law (scaled chi-squared) depends on sigma^2. Ancillarity is always relative to a specified parameter.

## completeness_statistic

- **spec:** full-rank exponential family: the natural sufficient statistic is complete (Laplace-transform uniqueness)
- **spec:** uniform(0, theta): X_(n) is complete -- E_theta[g(X_(n))] = 0 for all theta forces g = 0 by differentiating in theta
- **spec:** Bernoulli count sum X_i in {0,...,n}: complete (a degree-n polynomial with n+1 roots is zero)
- **drop `completeness`:** N(theta, theta^2) curved family: T = (sum X_i, sum X_i^2) is sufficient but E_theta[2(sum X_i)^2 - (n+1) sum X_i^2] = 0 for all theta with the bracket not identically 0 -- not complete. Lehmann-Scheffe then cannot certify a UMVUE.

## bounded_completeness

- **spec:** complete => boundedly complete (trivially)
- **spec:** there exist boundedly-complete-but-not-complete families (Lehmann-Scheffe example)
- **spec:** used in nonparametric IV: bounded completeness of the instrument given the endogenous regressor identifies the structural function
- **drop `bounded_completeness`:** a family rich enough to kill bounded unbiased-of-zero g but not unbounded ones -- rare in the parametric models here, central in nonparametric identification

## basu_theorem

- **spec:** N(mu, sigma^2) sigma^2 known: Xbar (complete sufficient for mu) _||_ S^2 (ancillary for mu). Gives Xbar _||_ S^2 with NO Jacobian computation.
- **spec:** uniform(0, theta): X_(n) (complete sufficient) _||_ (X_(1)/X_(n), ..., X_(n-1)/X_(n)) (ancillary ratios)
- **spec:** exponential(rate): sum X_i _||_ (X_1/sum X_i, ..., X_n/sum X_i) -- the normalized spacings
- **drop `completeness_statistic`:** drop completeness (curved family, or restricted parameter): T and A can be dependent even though A is ancillary and T is sufficient -- the standard Xbar _||_ S^2 shortcut is not available
- **drop `sufficiency`:** if T is complete but not sufficient the argument's first step (constant conditional given T) has no reason to hold

## estimator

- **spec:** Xbar as an estimator of a population mean
- **spec:** the MLE, the method-of-moments estimator, a Bayes posterior mean -- all estimators
- **spec:** an estimator of g(theta) need not be g(theta_hat) (that can be biased -- Jensen)
- **drop `valued_in_the_parameter_space`:** an 'estimator' of a variance that can return negative values (a naive ANOVA variance-component estimate) is ill-posed as a point in Theta = (0, inf); it must be truncated or the model rethought

## bias

- **spec:** S^2 (with n-1) is unbiased for sigma^2; the n-divisor version has bias -sigma^2/n
- **spec:** the MLE of sigma^2 in a normal model is biased low by a factor (n-1)/n
- **spec:** the MLE is generally biased at finite n but its bias is O(1/n), vanishing in the limit
- **drop `finite_mean`:** the MLE of the Cauchy scale from n=1 observation, or any estimator with heavy-tailed sampling distribution, may have no mean and hence no bias -- 'unbiased' is then not even a well-posed question

## mean_squared_error

- **spec:** MSE of Xbar for a population mean: sigma^2 / n (unbiased, so MSE = variance)
- **spec:** MSE of a shrinkage estimator c Xbar: c^2 sigma^2/n + (1-c)^2 mu^2 -- minimized at c < 1, beating Xbar at that mu
- **spec:** root-MSE is the natural scale; it has the units of theta
- **drop `finite_second_moment`:** estimators with infinite variance (Cauchy-scale MLE at small n, ratio estimators near a zero denominator) have infinite MSE though they may be perfectly usable (finite median absolute error)

## mse_bias_variance_decomposition

- **spec:** unbiased estimator: MSE = Var (bias term drops)
- **spec:** the constant estimator theta_hat = c: Var = 0, MSE = (c - theta)^2 -- all bias
- **spec:** ridge / shrinkage: trades a small positive bias^2 for a larger Var reduction, lowering MSE over a region of theta
- **drop `finite_second_moment`:** if Var(theta_hat) = inf the identity reads inf = inf + b^2 and carries no information

## unbiased_estimator

- **spec:** Xbar unbiased for the mean; S^2 (n-1 divisor) unbiased for the variance
- **spec:** there is NO unbiased estimator of 1/p in Bernoulli sampling (any function of the sufficient statistic is a polynomial in the count, of bounded degree)
- **spec:** the unique unbiased estimator of e^{-2 lambda} in Poisson sampling is (-1)^X -- unbiased but absurd (it is +-1)
- **drop `exists_at_all`:** e^{-2 lambda} Poisson: the (-1)^X estimator shows unbiasedness can pick out a ridiculous rule; the MLE e^{-2 Xbar} is biased but sensible

## consistency

- **spec:** Xbar is (strongly) consistent for the mean whenever E|X_1| < inf (SLLN)
- **spec:** S^2 is consistent for sigma^2 when E X_1^4 < inf
- **spec:** the sample maximum is consistent for theta in uniform(0, theta), at rate n
- **drop `finite_mean`:** Xbar for iid Cauchy: NOT consistent for the median theta -- Xbar is again Cauchy(theta, 1) for every n and never concentrates. The sample median IS consistent.
- **drop `for_every_theta`:** an estimator hard-coded to return theta_0 is consistent AT theta_0 only; it is inconsistent everywhere else

## asymptotic_variance

- **spec:** MLE: Sigma = I(theta)^{-1}
- **spec:** sample median of iid f: Sigma = 1 / (4 f(m)^2) where m is the population median
- **spec:** delta method: AVar(g(theta_hat)) = g'(theta)^T Sigma g'(theta)
- **drop `limit_of_scaled_variance`:** an estimator can be asymptotically N(0, Sigma) yet have Var(theta_hat_n) = inf for every n (a small-probability heavy tail that vanishes in the limit) -- report the asymptotic variance, not the (infinite) exact one

## asymptotic_normality_estimator

- **spec:** Xbar: sqrt(n)(Xbar - mu) -> N(0, sigma^2) whenever sigma^2 < inf (CLT)
- **spec:** the MLE under regularity: Sigma(theta) = I(theta)^{-1} (efficient)
- **spec:** a method-of-moments estimator: Sigma from the delta method applied to the moment map
- **drop `sqrt_n_rate`:** uniform(0, theta): n(theta - X_(n)) -> Exponential(1/theta), NOT a sqrt(n) normal limit -- 'asymptotic normality' as defined here simply does not hold

## relative_efficiency

- **spec:** sample mean vs sample median for a NORMAL location: ARE(median, mean) = 2/pi ~ 0.64 -- the median wastes ~36% of the data
- **spec:** for a Laplace (double-exponential) location: ARE(median, mean) = 2 -- the median is twice as efficient
- **spec:** for t_3 errors the median beats the mean; the crossover is around 'tails heavier than t_5'
- **drop `same_rate`:** comparing a sqrt(n) estimator to an n-rate estimator (uniform endpoint) by an ARE is meaningless -- the ratio degenerates to 0 or inf

## asymptotic_efficiency

- **spec:** MLE under regularity: efficient
- **spec:** method-of-moments: efficient only when the moment equations coincide with the score (exponential family, natural parametrization)
- **spec:** one-step Newton from a sqrt(n)-consistent start: efficient (the 'one-step estimator')
- **drop `for_all_theta`:** Hodges' estimator (shrink Xbar to 0 when |Xbar| < n^{-1/4}) has asymptotic variance 0 at theta = 0 and sigma^2 elsewhere -- 'superefficient' at one point, but its finite-sample maximum risk blows up near 0. Superefficiency on a Lebesgue-null set is the only way to beat I^{-1}, and it is not a free lunch.

## umvue

- **spec:** N(mu, sigma^2): Xbar is UMVUE of mu; S^2 is UMVUE of sigma^2 (both are unbiased functions of the complete sufficient (Xbar, S^2))
- **spec:** uniform(0, theta): (n+1)/n * X_(n) is the UMVUE of theta (unbiased function of the complete sufficient X_(n))
- **spec:** Bernoulli: Xbar is UMVUE of p; Xbar(1-Xbar) n/(n-1) is UMVUE of p(1-p)
- **drop `exists`:** for a curved exponential family the sufficient statistic is not complete and a UMVUE may fail to exist -- there can be two unbiased estimators neither dominating the other
- **drop `unbiased_class_is_the_right_one`:** the UMVUE can be beaten in MSE by a biased estimator (James-Stein beats the UMVUE Xbar for a >=3-dim normal mean)

## cramer_rao_lower_bound

- **spec:** Bernoulli(p) unbiased: Var >= p(1-p)/n -- attained by Xbar, so Xbar is efficient
- **spec:** Poisson(lambda) unbiased: Var >= lambda/n -- attained by Xbar
- **spec:** N(mu, sigma^2), estimating sigma^2 unbiasedly: Var >= 2 sigma^4 / n -- S^2 has variance 2 sigma^4/(n-1) > the bound, so NO unbiased estimator of sigma^2 attains the CRLB
- **spec:** biased form: for the MLE of sigma^2 (divisor n) the (1 + b')^2 numerator with b = -sigma^2/n gives a smaller bound, consistent with its smaller variance
- **drop `support_independent_of_theta`:** uniform(0, theta): the naive CRLB gives Var >= theta^2/n, but (n+1)/n X_(n) has variance ~ theta^2/n^2 -- it BEATS the 'bound' by a factor n. The regularity failure makes the CRLB inapplicable, not merely loose.
- **drop `interchange_derivative_integral`:** if d/dtheta and int do not commute, Cov(theta_hat, U) != 1 + b' and the bound is simply wrong
- **drop `unbiased_estimator`:** for biased estimators the bound has the (1 + b')^2 numerator; quoting 1/(nI) for a biased estimator is a category error

## rao_blackwell_theorem

- **spec:** Bernoulli, estimating p^2: start with theta_hat = X_1 X_2 (unbiased, crude); condition on T = sum X_i to get theta_hat_RB = [T(T-1)] / [n(n-1)], the UMVUE
- **spec:** estimating P(X_1 <= c) in a normal model: start with 1{X_1 <= c}, condition on (Xbar, S^2)
- **spec:** if theta_hat is already a function of T, Rao-Blackwell returns it unchanged
- **drop `sufficiency`:** condition on a NON-sufficient statistic T and E[theta_hat | T] depends on theta -- it is not a usable estimator. The variance would still drop, but you cannot compute the thing.
- **drop `finite_variance`:** if Var(theta_hat) = inf the inequality is vacuous

## lehmann_scheffe_theorem

- **spec:** N(mu, sigma^2): (Xbar, S^2) complete sufficient => Xbar is the unique UMVUE of mu, S^2 of sigma^2
- **spec:** uniform(0, theta): X_(n) complete sufficient => (n+1)/n X_(n) is the unique UMVUE of theta
- **spec:** two routes to the UMVUE: (a) guess an unbiased function of T; (b) Rao-Blackwell any unbiased estimator onto T -- both give the same phi(T)
- **drop `completeness_statistic`:** curved family N(theta, theta^2): sufficient statistic not complete; there is no UMVUE -- two unbiased estimators of theta exist with crossing variance functions
- **drop `sufficiency`:** an unbiased function of a complete-but-not-sufficient statistic is not improvable to the UMVUE by this route

## crlb_attainment

- **spec:** Bernoulli / Poisson / normal-mean: Xbar attains the CRLB for all n -- these are one-parameter exponential families with T = x
- **spec:** normal VARIANCE (mu known): sum(x_i - mu)^2 / n attains it for sigma^2? -- yes, T = (x - mu)^2 is the natural statistic; but the UNBIASED version /(n) with mu known does attain, while with mu unknown S^2 does not
- **spec:** estimating p(1-p), or sigma (not sigma^2), or 1/lambda: NOT the natural parameter -- no unbiased estimator attains the CRLB at finite n
- **drop `natural_parameter`:** estimating sigma (SD, not variance) in a normal model: even the UMVUE has variance strictly above 1/(nI) for every n, because sigma is a nonlinear function of the natural parameter -- the CRLB is unattainable, though approached as n -> inf

## method_of_moments

- **spec:** N(mu, sigma^2): m_1 = mu, m_2 = sigma^2 + mu^2 => mu_hat = Xbar, sigma^2_hat = (1/n) sum (X_i - Xbar)^2 (the /n version)
- **spec:** Gamma(a, b): match mean a/b and variance a/b^2 => a_hat, b_hat in closed form (the MLE needs iteration)
- **spec:** uniform(0, theta): m_1 = theta/2 => theta_hat = 2 Xbar -- which can be LESS than max X_i, an impossible estimate
- **drop `moments_exist`:** Cauchy or t_2: no finite mean / variance, so mbar_1, mbar_2 do not converge and the method produces nonsense (prob_cauchy_no_mean). Estimate the median / IQR instead.
- **drop `moment_map_invertible`:** if two parameter values give the same first d moments the system is not solvable for theta

## plug_in_principle

- **spec:** T(P) = E_P[X] => plug-in is Xbar; T(P) = Var_P(X) => plug-in is the /n sample variance
- **spec:** T(P) = F^{-1}(1/2) => plug-in is the sample median
- **spec:** T(P) = P(X in A) => plug-in is the sample proportion
- **drop `T_continuous`:** the density value f(x_0) is NOT a continuous functional of P in the sup metric -- there is no sqrt(n) plug-in estimator; density estimation is a genuinely nonparametric (slower-rate) problem (see kde_bias_variance_tradeoff)

## maximum_likelihood_estimator

- **spec:** Bernoulli: p_hat = Xbar; Poisson: lambda_hat = Xbar; N(mu, sigma^2): mu_hat = Xbar, sigma^2_hat = (1/n) sum (X_i - Xbar)^2 (divisor n -- biased)
- **spec:** uniform(0, theta): theta_hat = max X_i -- the argmax is at the boundary, the score equation has no root
- **spec:** logistic regression: no closed form; Newton-Raphson / IRLS on the concave log-likelihood
- **drop `argmax_exists`:** a two-component normal mixture with a free component variance: ell -> +inf as one component's variance -> 0 around a single data point -- the global MLE does not exist (only a consistent local maximizer does)
- **drop `argmax_unique`:** a periodic likelihood (circular / phase parameter) can have multiple equal maxima

## mle_score_equation

- **spec:** Bernoulli: U(p) = (sum x_i)/p - (n - sum x_i)/(1-p) = 0  =>  p_hat = xbar
- **spec:** exponential family: U(eta) = sum T(x_i) - n grad A(eta) = 0  =>  grad A(eta_hat) = Tbar  (moment matching)
- **spec:** uniform(0, theta): U(theta) = -n/theta, never 0 -- the MLE max x_i is NOT found this way
- **drop `true_parameter_interior`:** boundary MLE (uniform endpoint; a variance component estimated at 0; a probability estimated at exactly 0 or 1 in a small sample) -- U(theta_hat) != 0 and the score equation is the wrong tool
- **drop `differentiability`:** non-smooth log-likelihood (Laplace location -> sample median): U is a step function, 0 is 'crossed' not 'hit'

## mle_invariance

- **spec:** MLE of sigma is sqrt of the MLE of sigma^2 (which uses divisor n)
- **spec:** MLE of the odds p/(1-p) is Xbar/(1-Xbar)
- **spec:** MLE of P(X > c) in N(mu, sigma^2) is 1 - Phi((c - Xbar)/sigma_hat)
- **drop `bias_is_not_preserved`:** invariance is about the argmax, NOT about unbiasedness -- g(theta_hat) is typically biased even if theta_hat was unbiased (Jensen). E.g. sqrt(S^2) is a biased estimator of sigma.

## mle_consistency

- **spec:** all exponential families on the interior: consistent
- **spec:** N, Gamma, Poisson, logistic regression (with non-degenerate design): consistent
- **spec:** well-separated mixture models: the consistent ROOT of the likelihood equation exists even when the global MLE does not
- **drop `identifiability`:** N(alpha + beta, 1): (alpha_hat, beta_hat) is NOT consistent -- it wanders along the ridge alpha + beta = Xbar. Only the identified function alpha + beta is consistently estimated.
- **drop `regularity_uniform_LLN`:** Neyman-Scott problem: N(mu_i, sigma^2) with one mu_i per observation and n -> inf. The number of parameters grows with n; the MLE of sigma^2 converges to sigma^2/2, NOT sigma^2 -- inconsistent. Fixed finite d is essential.

## mle_asymptotic_normality

- **spec:** Bernoulli: sqrt(n)(p_hat - p) -> N(0, p(1-p)) -- the de Moivre-Laplace / normal approximation to the binomial proportion
- **spec:** N(mu, sigma^2): sqrt(n)((mu_hat, sigma^2_hat) - (mu, sigma^2)) -> N(0, diag(sigma^2, 2 sigma^4)) -- mu_hat and sigma^2_hat asymptotically independent
- **spec:** logistic regression: sqrt(n)(beta_hat - beta) -> N(0, (E[p(1-p) x x^T])^{-1}) -- the basis of the reported z-values
- **drop `log_likelihood_smooth`:** Laplace location: the MLE (sample median) IS sqrt(n)-normal but with variance 1 (= 1/(4 f(0)^2)), reached by a non-Taylor argument -- the C^3 route fails though the conclusion's SHAPE survives
- **drop `support_independent_of_theta`:** uniform(0, theta): n(theta - theta_hat) -> Exponential -- rate n, non-normal limit; the theorem's conclusion is simply false
- **drop `true_parameter_interior`:** one-sided boundary (variance component = 0): the limit is a half-normal, not a normal
- **drop `fisher_information_positive_definite`:** non-identified direction: I singular, I^{-1} undefined, no sqrt(n)-normal limit along the flat direction

## m_estimator

- **spec:** Huber's robust location estimator: psi(x) = clip(x - theta, -c, c) -- bounded influence, resists outliers
- **spec:** quantile regression: m(x; theta) = rho_tau(y - x^T theta), the check function -- estimates conditional quantiles
- **spec:** quasi-likelihood / GEE: psi from a mean model only, no full distribution
- **drop `estimating_equation_unbiased`:** if E_theta[psi(X; theta)] != 0 (a misspecified mean model, or Huber's psi under an asymmetric error) the M-estimator converges to the wrong value theta* -- the solution of E[psi(X; theta*)] = 0, not theta

## sandwich_variance

- **spec:** OLS with heteroskedastic errors: the HC0-HC3 'robust' / 'Huber-White' standard errors are the sandwich with psi = x(y - x^T beta)
- **spec:** GEE (longitudinal data): the sandwich gives valid SEs even if the working correlation is wrong
- **spec:** a correctly specified GLM: sandwich SE approx model-based SE (they diverge => evidence of misspecification -- an informal specification test)
- **drop `finite_meat_and_bread`:** if B = E[psi psi^T] is infinite (heavy-tailed influence) the sandwich variance is infinite and no sqrt(n) normal limit holds

## bayes_estimator

- **spec:** squared-error loss: delta_pi(x) = posterior mean E[theta | x] (posterior_mean_rule)
- **spec:** absolute-error loss: delta_pi(x) = a posterior median (posterior_median_rule)
- **spec:** 0-1 loss on a discrete Theta: delta_pi(x) = the posterior mode (MAP estimate)
- **drop `proper_posterior`:** an improper prior can yield an improper posterior (e.g. pi(sigma) = 1/sigma with n = 0, or the Bayes/Neyman-Scott hierarchical models) -- then no Bayes estimator exists and reported 'posterior summaries' are meaningless
- **drop `finite_posterior_loss`:** squared-error loss with a Cauchy posterior: E[theta | x] does not exist; use the posterior median

## posterior_mean_rule

- **spec:** Beta-Bernoulli: prior Beta(alpha, beta), data sum x_i = s in n trials => posterior Beta(alpha + s, beta + n - s), posterior mean (alpha + s)/(alpha + beta + n) -- a shrunk version of s/n toward the prior mean
- **spec:** Normal-Normal: prior N(mu_0, tau^2), data Xbar with known sigma^2/n => posterior mean is a precision-weighted average of mu_0 and Xbar
- **spec:** as n -> inf the posterior mean -> the MLE (Bernstein-von Mises)
- **drop `posterior_mean_exists`:** heavy-tailed posterior (Cauchy prior + one observation): E[theta | x] is undefined; the posterior-median rule (absolute loss) still works
- **drop `squared_loss_appropriate`:** if over- and under-estimation have different costs (inventory, dosing) the posterior mean is the wrong summary -- use the rule for the actual asymmetric loss

## posterior_median_rule

- **spec:** a symmetric unimodal posterior: median = mean = mode, all three rules agree
- **spec:** a right-skewed posterior (variance, rate parameters): posterior median < posterior mean -- the median is the more stable point summary
- **spec:** check loss (quantile) generalization: L_tau(theta, a) = (tau - 1{theta < a})(theta - a) gives the tau-th posterior quantile
- **drop `none_all_hypotheses_essential`:** the rule needs only that the posterior has a median (always true) and finite E|theta| for the risk to be finite -- weaker than the posterior-mean rule's requirement

## conjugate_prior

- **spec:** Beta is conjugate to Bernoulli/binomial: Beta(a, b) + s successes in n => Beta(a + s, b + n - s)
- **spec:** Gamma is conjugate to Poisson: Gamma(a, b) + counts summing to S in n obs => Gamma(a + S, b + n)
- **spec:** Normal-inverse-Gamma is conjugate to the normal with unknown mean and variance
- **spec:** Dirichlet is conjugate to the multinomial
- **drop `exists_and_is_flexible_enough`:** conjugate priors can be too rigid -- e.g. the Beta cannot be bimodal, the Gamma cannot have a heavy left tail; a genuinely different prior belief forces non-conjugate computation (MCMC)

## credible_interval

- **spec:** Beta(a+s, b+n-s) posterior: the equal-tailed 95% credible interval is (Beta quantile 0.025, Beta quantile 0.975)
- **spec:** Normal-Normal: the credible interval is posterior mean +- 1.96 posterior SD (posterior is Gaussian)
- **spec:** HPD vs equal-tailed: identical for a symmetric posterior; HPD is shorter and can be disjoint for a bimodal posterior
- **drop `proper_posterior`:** an improper posterior (from an improper prior with no finite normalizer) has no credible interval -- reported intervals are then meaningless
- **drop `prior_is_defensible`:** a 95% credible interval inherits the prior; with a strong prior and little data it mostly reflects the prior, which must be disclosed

## bernstein_von_mises

- **spec:** Beta(a,b)-Bernoulli: the Beta(a + s, b + n - s) posterior is asymptotically N(p_hat, p_hat(1-p_hat)/n) -- matches the Wald interval
- **spec:** the prior choice affects only the O(1/n) correction for large n
- **spec:** the practical upshot: for regular parametric models, large-sample Bayesian and frequentist intervals agree
- **drop `true_parameter_interior`:** boundary parameter (a variance component at 0): the posterior piles up against the boundary and is NOT asymptotically normal; credible intervals do NOT have frequentist coverage
- **drop `fixed_finite_dimension`:** in nonparametric / high-dimensional models Bernstein-von Mises can FAIL -- credible bands can badly under- or over-cover (Cox 1993, Freedman 1999); this is an active research area
- **drop `identifiability`:** non-identified parameter: the posterior does not concentrate and coverage is prior-driven

## loss_function

- **spec:** estimation: A = Theta, L = (theta - a)^2 or |theta - a|
- **spec:** testing: A = {0, 1}, L(theta, a) = 1{a wrongly rejects/accepts} -- possibly weighted by how wrong
- **spec:** asymmetric: newsvendor loss L(theta, a) = c_o (a - theta)_+ + c_u (theta - a)_+ for over/under-stocking
- **drop `loss_reflects_real_consequences`:** using squared-error loss when the real cost is a step function (a dam either overtops or not) gives a Bayes rule optimizing the wrong thing

## risk_function

- **spec:** squared-error loss: R(theta, delta) = MSE(theta) = Var + bias^2
- **spec:** 0-1 loss in testing: R(theta, delta) = P_theta(wrong decision) -- the error probability
- **spec:** the constant rule delta = c has R(theta) = L(theta, c), typically 0 at theta = c and large elsewhere
- **drop `expectation_exists`:** a rule whose loss has infinite expectation under some theta (an estimator with infinite MSE) has undefined risk there and cannot be compared by risk

## decision_rule

- **spec:** an estimator theta_hat(.) is a decision rule with A = Theta
- **spec:** a test phi(.) in [0,1] is a randomized decision rule with A = {0,1}
- **spec:** 'always report 5' and 'flip a coin' are (bad) decision rules
- **drop `measurable`:** a non-measurable rule has no well-defined risk -- excluded

## admissibility

- **spec:** Xbar is admissible for a 1- or 2-dimensional normal mean under squared-error loss
- **spec:** every unique Bayes rule is admissible; a Bayes rule with continuous risk is admissible
- **spec:** a constant estimator delta = c is admissible (nothing beats it at theta = c) -- admissibility alone is weak
- **drop `dimension`:** Xbar is INADMISSIBLE for a normal mean in dimension d >= 3 -- the James-Stein estimator dominates it everywhere (james_stein). This is the famous Stein paradox.

## minimax_rule

- **spec:** N(theta, 1) known variance, Theta = R: Xbar is minimax (constant risk 1/n, and it is Bayes vs the flat improper prior limit)
- **spec:** Bernoulli(p), Theta = [0,1], squared-error loss: the minimax estimator is (sum X_i + sqrt(n)/2) / (n + sqrt(n)) -- a Beta(sqrt(n)/2, sqrt(n)/2) Bayes rule, with constant risk
- **spec:** bounded normal mean |theta| <= tau: the minimax rule is nonlinear and shrinks toward 0
- **drop `Theta_bounded_or_risk_controlled`:** if Theta is unbounded and risk is unbounded, sup_theta R can be infinite for every rule and 'minimax' is degenerate -- restrict Theta or the loss

## bayes_risk

- **spec:** r(pi, delta) = E_X[ posterior expected loss at X ] -- the two-way expectation can be taken in either order (Fubini)
- **spec:** the minimizer over delta is delta_pi, the Bayes rule (posterior-loss minimizer)
- **spec:** sup_pi inf_delta r(pi, delta) = the minimax risk when a saddle point exists (minimax theorem)
- **drop `prior_proper_or_r_finite`:** an improper prior with infinite Bayes risk gives no minimizer; 'generalized Bayes' rules (formal posterior mean) may still be admissible but are not Bayes in this sense

## bayes_rule_minimizes_bayes_risk

- **spec:** squared-error loss => delta_pi = posterior mean (posterior_mean_rule)
- **spec:** absolute loss => posterior median; 0-1 loss => posterior mode
- **spec:** the theorem is what licenses 'just compute the posterior and summarize it' as an optimal procedure
- **drop `inner_min_attained`:** if argmin_a E[L(theta,a)|x] is empty (loss not lower-semicontinuous, or infinite everywhere) there is no Bayes rule -- e.g. squared loss with a Cauchy posterior

## complete_class

- **spec:** consequence: if you want an admissible rule, look among (generalized) Bayes rules -- e.g. James-Stein is a generalized (empirical) Bayes rule
- **spec:** in the normal-mean problem the admissible estimators are exactly the generalized Bayes ones (Brown 1971)
- **spec:** for one-sided testing, the complete class is the set of monotone tests (Karlin-Rubin's structural half)
- **drop `convex_loss_compact_Theta`:** without convexity of the loss, randomized rules can be admissible and not Bayes; without compactness the closure operation is essential and 'generalized Bayes' rules that are not proper Bayes appear (Xbar itself is one)

## james_stein

- **spec:** d = 1, 2: no estimator dominates X -- shrinkage cannot uniformly help (the (d-2) factor is <= 0)
- **spec:** the positive-part James-Stein max(0, 1 - (d-2)/||X||^2) X dominates the raw JS and is closer to admissible (still not admissible)
- **spec:** shrinkage toward the grand mean, or toward a regression fit, works too -- the target is arbitrary
- **drop `d_at_least_3`:** in d <= 2, X IS admissible -- the paradox is genuinely a high-dimensional phenomenon
- **drop `the_loss_is_TOTAL_squared_error`:** James-Stein improves the SUM of squared errors; a single coordinate's MSE can get WORSE. If you care about one coordinate, shrinkage can hurt you.

## chi_squared_distribution

- **spec:** k = 1: the law of Z^2, density (2 pi x)^{-1/2} e^{-x/2}
- **spec:** k = 2: Exponential(rate 1/2)
- **spec:** large k: chi^2_k approx N(k, 2k) (CLT on the sum of squares); sqrt(2 chi^2_k) - sqrt(2k-1) approx N(0,1) is more accurate
- **drop `independence_of_the_Z_i`:** if the Z_i are correlated, sum Z_i^2 is a quadratic form Z^T Z with Z ~ N(0, Sigma); its law is a weighted sum of chi^2_1's (eigenvalues of Sigma), not chi^2_k
- **drop `standard_normal_summands`:** sum of squares of N(mu_i, 1) is NONCENTRAL chi^2_k(lambda), lambda = sum mu_i^2 -- the distribution under a testing alternative

## students_t_distribution

- **spec:** k = 1: the standard Cauchy (no mean, no variance)
- **spec:** k -> inf: t_k -> N(0,1) (V/k -> 1 by the LLN, then Slutsky)
- **spec:** k = 2: E|T| < inf but Var = inf
- **drop `independence_Z_V`:** if Z and V are dependent the ratio is not t-distributed -- the entire justification of the one-sample t-test rests on Xbar _||_ S^2 for a NORMAL sample (fails for non-normal data at small n)
- **drop `V_is_chi_squared`:** if V is a scaled chi^2 with the wrong df (correlated observations reducing the effective df) the nominal t_k reference is wrong and the test mis-calibrates

## f_distribution

- **spec:** d1 = 1: F_{1,d2} = (t_{d2})^2
- **spec:** d2 -> inf: d1 * F_{d1,d2} -> chi^2_{d1} (the denominator -> 1)
- **spec:** the ANOVA and regression overall-F tests use F_{q, n-p}
- **drop `independence_U_V`:** in an unbalanced or misspecified ANOVA the numerator and denominator sums of squares can be dependent -- the nominal F reference is then wrong (Cochran's theorem is exactly the check that they are independent)
- **drop `both_chi_squared`:** under the alternative, U is NONCENTRAL chi^2 -- the test statistic has a noncentral F distribution, which is how power is computed

## chi_squared_additivity

- **spec:** k independent chi^2_1's sum to chi^2_k -- recovers the sum-of-squared-normals definition
- **spec:** partition the residual sum of squares in a two-factor ANOVA: the component df add to n - 1
- **spec:** sequential model building: each added block of q predictors contributes an independent chi^2_q to the explained sum of squares (orthogonal design)
- **drop `independence`:** U and V = c U dependent: U + V = (1+c) U ~ (1+c) chi^2_a, NOT chi^2_{2a} -- df do not add without independence

## sample_mean

- **spec:** Xbar is the MLE of mu in N(mu, sigma^2), the UMVUE of the mean, and the method-of-moments estimator -- all coincide
- **spec:** Xbar -> E[X_1] a.s. (SLLN) and sqrt(n)(Xbar - mu) -> N(0, sigma^2) (CLT)
- **spec:** for a normal sample, Xbar ~ N(mu, sigma^2/n) EXACTLY (not just asymptotically)
- **drop `finite_mean`:** Xbar of iid Cauchy is again Cauchy(mu, 1) -- it does not concentrate and is a useless estimator of the center (use the median)

## sample_variance

- **spec:** N(mu, sigma^2): (n - 1) S^2 / sigma^2 ~ chi^2_{n-1} exactly (scaled_sample_variance_chi_squared)
- **spec:** S^2 is the UMVUE of sigma^2 for a normal sample; the MLE uses divisor n and is biased low
- **spec:** S (not S^2) is a biased estimator of sigma even though S^2 is unbiased for sigma^2 (Jensen: E[S] < sigma)
- **drop `finite_fourth_moment`:** Var(S^2) = (1/n)(mu_4 - (n-3)/(n-1) sigma^4); if E X^4 = inf then S^2 has infinite variance and is an unstable estimator (t_3, t_4 data)

## bias_of_sample_variance

- **spec:** n = 1: sum (X_1 - X_1)^2 = 0 = 0 . sigma^2 -- consistent, and S^2 is undefined (0/0), matching 'you cannot estimate spread from one point'
- **spec:** n = 2: E[(X_1 - X_2)^2 / 2] = sigma^2
- **spec:** the divisor-n version has expectation (n-1)/n sigma^2 -- bias -sigma^2/n, vanishing as n -> inf
- **drop `finite_variance`:** if sigma^2 = inf (Cauchy, t_2) the left side is infinite and 'unbiased for sigma^2' is vacuous -- S^2 estimates nothing

## normal_sample_mean_variance_independence

- **spec:** n = 2: Xbar = (X_1 + X_2)/2 and S^2 = (X_1 - X_2)^2/2 are functions of the orthogonal pair (X_1 + X_2, X_1 - X_2), which are independent for a bivariate spherical normal
- **spec:** gives the numerator-denominator independence in the t-statistic sqrt(n)(Xbar - mu)/S
- **spec:** and the independence of the ANOVA / regression 'model' and 'error' sums of squares
- **drop `normality`:** exponential sample: Xbar and S^2 are POSITIVELY correlated (both driven up by a large observation). The one-sample t-statistic is then not exactly t-distributed and the t-test's level is off at small n. Independence of Xbar and S^2 for all n is a *characterization* of the normal (Geary 1936, Lukacs 1942).

## scaled_sample_variance_chi_squared

- **spec:** n = 2: S^2 = (X_1 - X_2)^2 / 2, so S^2/sigma^2 = ((X_1 - X_2)/(sigma sqrt 2))^2 ~ chi^2_1 -- matches n - 1 = 1
- **spec:** gives E[S^2] = sigma^2 (mean of chi^2_{n-1} is n-1) and Var(S^2) = 2 sigma^4/(n-1)
- **spec:** the pivot for the normal-variance confidence interval (normal_variance_ci)
- **drop `normality`:** for non-normal data (n-1)S^2/sigma^2 is not chi^2_{n-1}; its mean is still n-1 (bias_of_sample_variance holds generally) but its variance and shape depend on the kurtosis. The chi^2 variance interval is then badly miscalibrated -- far worse than the t interval for the mean is under non-normality.

## t_statistic_distribution

- **spec:** n = 2: sqrt(2)(Xbar - mu)/S = (X_1 + X_2 - 2mu) / |X_1 - X_2| ~ t_1 = Cauchy -- the extreme small-sample case, infinitely heavy tails
- **spec:** n large: t_{n-1} -> N(0,1); for n >= 30 the difference in the 97.5th percentile is under 5%
- **spec:** the pivot (it does not depend on mu or sigma) for the one-sample t confidence interval and test
- **drop `normality`:** for skewed data at small n the statistic is not t-distributed (both Xbar/S independence and the chi^2 denominator fail); the t-test's actual level can be well off 5%. For large n the CLT + Slutsky rescue it (-> N(0,1)) REGARDLESS of the parent, which is why the t-test is 'robust in level' asymptotically but not for small skewed samples.
- **drop `iid`:** correlated observations inflate the true variance of Xbar while S^2 underestimates it -- the t-statistic is then too large and the test over-rejects

## cochran_theorem

- **spec:** one-way ANOVA: Z^T Z = (between-groups SS) + (within-groups SS) with ranks (k - 1) + (n - k) = n - 1 after centering -- the F-test's numerator and denominator
- **spec:** sample variance: I - (1/n) J has rank n - 1, (1/n) J has rank 1, sum = n -- gives scaled_sample_variance_chi_squared and Xbar _||_ S^2 in one stroke
- **spec:** regression: fitted SS (rank p) + residual SS (rank n - p)
- **drop `sum_of_ranks_equals_n`:** if sum r_j < n the components need not be chi^2 or independent (there is 'leftover' variation); if the A_j are not idempotent (a general quadratic form) the law is a weighted sum of chi^2_1's
- **drop `Z_spherical`:** for Z ~ N(0, Sigma), Sigma != I, apply to Sigma^{-1/2} Z; forgetting the whitening gives wrong df

## one_way_anova_identity

- **spec:** k = 2 groups: the ANOVA F reduces to the square of the pooled two-sample t-statistic (F_{1, N-2} = t_{N-2}^2)
- **spec:** one observation per group (n_i = 1): SS_within = 0, no error estimate -- the design is degenerate
- **spec:** R^2 for the ANOVA = SS_between / SS_total = eta^2
- **drop `equal_group_variances`:** if the groups have different sigma_i^2 the F-statistic is not F-distributed under H0 (the Behrens-Fisher problem); Welch's ANOVA adjusts the df
- **drop `normality`:** the identity is algebraic and always holds; the chi^2 / F distribution of the pieces needs normal errors (or large n_i via the CLT)

## one_sample_t_test

- **spec:** paired design: apply to the within-pair differences d_i = X_i - Y_i, testing H0: mean difference = 0
- **spec:** one-sided: H0: mu <= mu_0 vs H1: mu > mu_0, reject for large t -- UMP by Karlin-Rubin (MLR in Xbar)
- **spec:** the dual t confidence interval is Xbar +- t S/sqrt(n) (normal_mean_ci_unknown_variance)
- **drop `normality`:** small skewed samples: the actual size deviates from alpha (up to ~0.08-0.10 for strongly skewed n ~ 10); large n rescues the LEVEL via the CLT (t -> N(0,1) regardless of parent) but not necessarily the power comparison
- **drop `iid`:** correlated data (repeated measures analysed as independent): the true SE of Xbar is underestimated, t is inflated, the test over-rejects badly

## two_sample_t_test

- **spec:** n = m and equal variances: pooled and Welch give nearly identical results
- **spec:** very unequal variances or sample sizes: pooled test can be badly miscalibrated -- Welch is the safer default (and is now the default in R's t.test)
- **spec:** the ANOVA F-test with k = 2 groups equals the pooled two-sample t^2
- **drop `equal_variances_for_the_pooled_version`:** n=5 with sigma_X = 1 and m=50 with sigma_Y = 4: the pooled t-test's true size can be 0.15+ at nominal 0.05 -- pooling a large-sample large-variance group drags S_p^2 wrongly. Use Welch.
- **drop `normality`:** same small-sample skew caveat as the one-sample test
- **drop `independence_between_samples`:** matched/paired data must use the one-sample test on differences -- treating pairs as independent throws away the pairing and usually loses power

## f_test_equality_of_variances

- **spec:** used as a (poor) preliminary check before a pooled two-sample t-test -- this two-stage procedure is now discouraged; just use Welch
- **spec:** one-sided: test whether a new process REDUCES variance
- **spec:** k-sample generalization: Bartlett's test (also non-robust) or Levene's test (robust)
- **drop `normality`:** with heavy-tailed data (kurtosis > 3) the F-test for variances has true size FAR above nominal -- e.g. 0.20 at nominal 0.05 for t_5 data. This is the textbook example of a procedure that must not be used without near-exact normality.
- **drop `independence`:** paired or correlated samples invalidate the chi^2 factorization

## confidence_set

- **spec:** exact: Xbar +- t_{n-1, 1-alpha/2} S/sqrt(n) for a normal mean -- coverage exactly 1 - alpha
- **spec:** asymptotic: theta_hat +- z_{1-alpha/2} SE -- coverage -> 1 - alpha
- **spec:** conservative: a Bonferroni-adjusted simultaneous set has coverage >= 1 - alpha, often strictly
- **drop `coverage_for_every_theta`:** the Wald interval for a binomial p has coverage that DIPS well below 1 - alpha for p near 0 or 1 and small n (down to ~0.8 for a nominal 0.95) -- the Clopper-Pearson or Wilson interval fixes it
- **drop `the_set_is_pre-specified`:** choosing which parameter to bracket after seeing the data (selective inference) destroys the coverage guarantee

## coverage_probability

- **spec:** normal mean t-interval: beta_C(theta) = 1 - alpha exactly, for all (mu, sigma^2)
- **spec:** binomial Clopper-Pearson: beta_C(p) >= 1 - alpha always, with sawtooth over-coverage
- **spec:** binomial Wald: beta_C(p) oscillates and undershoots badly near the boundary
- **drop `none_all_hypotheses_essential`:** coverage is defined for any procedure; the content is whether inf_theta beta_C >= 1 - alpha

## pivotal_quantity

- **spec:** N(mu, sigma^2 known): Q = sqrt(n)(Xbar - mu)/sigma ~ N(0,1), pivotal
- **spec:** N(mu, sigma^2): Q = sqrt(n)(Xbar - mu)/S ~ t_{n-1}, pivotal
- **spec:** N(mu, sigma^2): Q = (n-1) S^2 / sigma^2 ~ chi^2_{n-1}, pivotal for sigma^2
- **spec:** any continuous F_theta: Q = F_theta(X) ~ Uniform(0,1) -- the probability integral transform is a universal (if often intractable) pivot
- **drop `exactly_theta_free_law`:** an ASYMPTOTIC pivot (theta_hat - theta)/SE -> N(0,1) is only approximately pivotal at finite n -- the resulting Wald interval has approximate coverage
- **drop `Behrens-Fisher`:** (Xbar - Ybar - delta) / sqrt(S_X^2/n + S_Y^2/m) is NOT exactly pivotal when sigma_X != sigma_Y -- its df depends on the unknown ratio (hence Welch's approximation)

## pivot_method

- **spec:** normal mean, sigma known: invert -z <= sqrt(n)(Xbar - mu)/sigma <= z  =>  Xbar +- z sigma/sqrt(n)
- **spec:** normal variance: invert chi^2_{lo} <= (n-1)S^2/sigma^2 <= chi^2_{hi}  =>  ( (n-1)S^2/chi^2_{hi}, (n-1)S^2/chi^2_{lo} ) -- asymmetric
- **spec:** the choice of (a, b) is free; equal-tailed is conventional, shortest-interval is an alternative
- **drop `pivotal_quantity`:** with only an asymptotic pivot the coverage is 1 - alpha + O(n^{-1/2}) -- the method still 'works' but is no longer exact
- **drop `monotone_in_theta`:** if Q is not monotone in theta the inverted set can be a union of intervals or empty

## confidence_set_test_duality

- **spec:** the t-interval Xbar +- t S/sqrt(n) is exactly the set of mu_0 NOT rejected by the two-sided one-sample t-test
- **spec:** inverting the LRT gives the likelihood-ratio confidence interval; inverting the score test gives the score interval (Wilson, for a proportion)
- **spec:** a UMP test inverts to a uniformly most accurate (shortest expected length among unbiased) confidence set
- **drop `none_all_hypotheses_essential`:** the duality is a definitional equivalence; the only requirement is that the test have level alpha (or the CI have coverage 1 - alpha)

## normal_mean_ci_known_variance

- **spec:** alpha = 0.05: Xbar +- 1.96 sigma/sqrt(n)
- **spec:** the 'margin of error' of a poll (with sigma^2 = p(1-p) plugged in) -- a slight abuse since sigma^2 is then estimated
- **spec:** sample size for a target width w: n = (2 z sigma / w)^2
- **drop `sigma_known`:** sigma is essentially never known; using an estimate S in the z-interval undercovers at small n -- that is exactly why the t-interval exists (normal_mean_ci_unknown_variance)
- **drop `normality`:** for non-normal data the coverage is approximate (1 - alpha + O(n^{-1/2}) by the CLT), reasonable for large n

## normal_mean_ci_unknown_variance

- **spec:** n = 2, alpha = 0.05: t_{1, 0.975} = 12.7 -- the interval is enormous, honestly reflecting near-zero information about sigma
- **spec:** n >= 30: t_{n-1} approx z, the t- and z-intervals nearly coincide
- **spec:** paired data: apply to the within-pair differences
- **drop `normality`:** for skewed data at small n coverage departs from 1 - alpha (the t-interval is more robust than the chi^2 variance interval but not immune); a bootstrap-t or BCa interval can do better
- **drop `iid`:** positively correlated observations => S underestimates Var(Xbar) => the interval is too narrow => undercoverage

## normal_variance_ci

- **spec:** take sqrt of the endpoints for a CI on sigma (the SD)
- **spec:** n = 10, alpha = 0.05: the interval spans roughly (0.47 S^2, 3.3 S^2) -- variance is hard to pin down
- **spec:** the shortest 1 - alpha interval uses unequal tail probabilities chosen to minimize length
- **drop `normality`:** THIS PROCEDURE HAS NO ROBUSTNESS. For data with kurtosis != 3 (any non-normal shape) the coverage can be far from 1 - alpha even for large n, because (n-1)S^2/sigma^2 is not chi^2_{n-1} and its shape depends on the 4th moment. Use a bootstrap or a kurtosis-corrected interval.

## wald_interval

- **spec:** MLE: theta_hat +- z / sqrt(n I(theta_hat)) (large_sample_wald_interval)
- **spec:** binomial proportion: p_hat +- z sqrt(p_hat(1-p_hat)/n) -- the notorious Wald interval for p, which undercovers near 0 and 1
- **spec:** a transformed parameter g(theta): use the delta-method se |g'(theta_hat)| se(theta_hat) (delta_method_standard_error), or better, build the interval on the scale where normality is best and back-transform
- **drop `fisher_information_positive_definite`:** near a boundary (p near 0/1, a variance component near 0) the sampling distribution is skewed and one-sided; the symmetric Wald interval can extend outside the parameter space and badly undercover -- the score (Wilson) or LR interval is the fix
- **drop `sqrt_n_normality`:** for a non-sqrt(n) estimator (uniform endpoint) the Wald recipe is simply invalid

## delta_method_standard_error

- **spec:** odds ratio from log-odds: se(OR) = OR . se(log OR) -- but the CI is better built on the log scale and exponentiated
- **spec:** se of p_hat(1 - p_hat) is |1 - 2 p_hat| se(p_hat) -- ZERO at p_hat = 1/2, where the first-order method fails and Var(p_hat(1-p_hat)) = O(1/n^2)
- **spec:** se of a ratio Xbar/Ybar (Ybar bounded away from 0): the classic ratio-estimator variance formula
- **drop `g_prime_nonzero`:** g(theta) = theta^2 at theta = 0: g'(0) = 0, so the first-order delta method gives se = 0. The truth is n theta_hat^2 -> sigma^2 chi^2_1 -- a completely different (one-sided, non-normal) limit.
- **drop `g_differentiable`:** g(theta) = |theta| at 0, or a max/min functional -- not differentiable, delta method inapplicable

## large_sample_wald_interval

- **spec:** Poisson rate: lambda_hat +- z sqrt(lambda_hat / n) since I(lambda) = 1/lambda
- **spec:** logistic regression coefficients: the standard reported CI, beta_hat_j +- z se_j with se_j from the inverse observed information
- **spec:** prefer the profile-likelihood (LR) interval when the log-likelihood is visibly asymmetric
- **drop `true_parameter_interior`:** near a boundary the interval extends past the parameter space and undercovers -- use the LR interval, which respects the likelihood's shape
- **drop `log_likelihood_smooth`:** non-regular model: the interval is invalid (wrong rate / wrong shape)

## null_hypothesis

- **spec:** simple: H0: mu = 0 (Theta_0 a single point)
- **spec:** composite one-sided: H0: mu <= 0
- **spec:** composite with nuisance: H0: mu = 0, sigma^2 > 0 arbitrary
- **drop `specified_in_advance`:** choosing Theta_0 after seeing the data (testing the hypothesis the data suggest) invalidates the Type I error control -- 'the garden of forking paths'

## alternative_hypothesis

- **spec:** two-sided: H1: mu != 0 -- detect an effect in either direction
- **spec:** one-sided: H1: mu > 0 -- more powerful against positive effects, blind to negative ones
- **spec:** restricted: H1: theta in a cone (order-restricted alternatives)
- **drop `chosen_in_advance`:** switching from two-sided to one-sided after seeing a positive Xbar doubles the effective alpha

## test_function

- **spec:** phi(x) = 1{ T(x) > c } -- reject for large values of a test statistic T
- **spec:** two-sided: phi(x) = 1{ |T(x)| > c }
- **spec:** randomized: phi(x) = gamma when T(x) = c, to hit an exact size on a lattice
- **drop `measurable`:** a non-measurable rejection region has no size -- excluded

## size_of_test

- **spec:** one-sample t-test, H0: mu = mu_0: size exactly alpha (the t-statistic is pivotal under the whole null since it does not depend on sigma^2)
- **spec:** a composite null H0: mu <= 0: the size is attained at the boundary mu = 0
- **spec:** discrete data (binomial test): the achievable sizes form a lattice; a nonrandomized test is conservative (size < nominal alpha)
- **drop `sup_attained_or_controlled`:** if the null contains a nuisance parameter over which the rejection probability is not maximized at a computable point (Behrens-Fisher), the exact size is unknown and one uses an approximately-similar test

## power_function

- **spec:** one-sample z-test power at mu_1: Phi( sqrt(n)(mu_1 - mu_0)/sigma - z_{1-alpha} ) for a one-sided test
- **spec:** sample-size formula: solve beta_phi(mu_1) = 1 - beta for n given a target alternative mu_1 and power 1 - beta
- **spec:** the power of the LRT against local alternatives theta_0 + h/sqrt(n) tends to a noncentral chi^2 tail probability
- **drop `none_all_hypotheses_essential`:** the power function is defined for any test; the content is its shape

## type_i_error

- **spec:** drug trial: Type I = approve an ineffective drug (H0: no effect); Type II = miss an effective one
- **spec:** the trade-off at fixed n: lowering alpha raises the Type II rate; only increasing n lowers both
- **spec:** 5-sigma in particle physics: alpha ~ 3e-7, an extremely low Type I tolerance
- **drop `H0_is_the_costlier_false_positive`:** if the roles are mislabelled, the procedure rigidly protects the wrong error -- e.g. an equivalence trial must put 'the treatments differ' style framing correctly (H0: not equivalent)

## neyman_pearson_lemma

- **spec:** N(0,1) vs N(mu_1, 1), mu_1 > 0: f1/f0 is increasing in x, so the MP test is 1{ Xbar > c } -- the one-sided z-test; the SAME test is MP for every mu_1 > 0, which is why it is UMP one-sided
- **spec:** the ROC curve of a diagnostic test is exactly the NP power-vs-size trade-off as k varies
- **spec:** simple-vs-simple is the ONLY case with a clean 'most powerful' test; composite alternatives need MLR (Karlin-Rubin) or unbiasedness restrictions
- **drop `simple_hypotheses`:** for a composite two-sided alternative H1: mu != 0 there is NO uniformly most powerful test -- the MP test against mu_1 > 0 (reject for large Xbar) has power BELOW alpha against mu_1 < 0. One must add an unbiasedness or invariance restriction.
- **drop `known_f0_and_f1`:** if f0 or f1 has an unknown nuisance parameter the ratio is not a statistic and the lemma does not directly apply

## monotone_likelihood_ratio

- **spec:** every one-parameter exponential family with natural statistic T has MLR in T (the ratio is exp((eta_1 - eta_0) T - (A(eta_1) - A(eta_0))), increasing in T since eta_1 > eta_0)
- **spec:** N(theta, 1) in T = Xbar; Bernoulli(theta) in T = sum X_i; Uniform(0, theta) in T = X_(n) (a non-exponential-family example with MLR)
- **spec:** the noncentral t and noncentral chi^2 families have MLR in their natural statistics
- **drop `MLR_holds`:** the Cauchy location family does NOT have MLR -- the likelihood ratio is not monotone, there is no UMP one-sided test, and the one-sided testing problem genuinely has no best solution
- **drop `two_sided`:** MLR gives UMP tests only for ONE-SIDED hypotheses; for H0: theta = theta_0 vs H1: theta != theta_0 even an MLR family has no UMP test

## karlin_rubin_theorem

- **spec:** N(theta, sigma^2 known): the one-sided z-test 1{ Xbar > mu_0 + z sigma/sqrt(n) } is UMP for H0: mu <= mu_0
- **spec:** Bernoulli: the one-sided binomial test is UMP for H0: p <= p_0
- **spec:** one-sided F-test for a variance ratio; one-sided test for a noncentrality parameter
- **drop `monotone_likelihood_ratio`:** Cauchy location, or any family without MLR: no UMP one-sided test exists -- different alternatives are best detected by different regions
- **drop `one_sided`:** for H0: theta = theta_0 vs H1: theta != theta_0 (two-sided) there is no UMP test even under MLR; one restricts to unbiased tests (UMPU) and gets the equal-tailed two-sided test

## likelihood_ratio_test

- **spec:** N(mu, sigma^2), H0: mu = mu_0: -2 log Lambda is a monotone function of the t-statistic^2 -- the LRT IS the two-sided t-test
- **spec:** H0: several regression coefficients are 0: -2 log Lambda ~ the F-test (exactly, under normal errors) or chi^2_q (asymptotically)
- **spec:** multinomial goodness of fit: -2 log Lambda = 2 sum O_j log(O_j/E_j), the G-test, asymptotically chi^2 like Pearson's
- **drop `nested_models`:** Lambda requires Theta_0 subset Theta (nested); comparing NON-nested models needs AIC / BIC / Vuong's test, not the LRT
- **drop `regularity_for_the_chi2_limit`:** if H0 is on the boundary of Theta (a variance component = 0) the chi^2_r calibration is wrong (mixture of chi^2's) -- true_parameter_interior again

## wilks_theorem

- **spec:** one restriction (d - r = 1): -2 log Lambda -> chi^2_1, and sqrt(-2 log Lambda) is asymptotically |N(0,1)| -- matches the Wald and score tests
- **spec:** testing q of p regression coefficients zero: -2 log Lambda -> chi^2_q (and q F_{q, n-p} -> chi^2_q, so the exact F-test and Wilks agree in the limit)
- **spec:** the LRT confidence region { theta_0 : -2 log Lambda(theta_0) <= chi^2_{d, 1-alpha} } -- the profile-likelihood region
- **drop `true_parameter_interior`:** H0 on the boundary (sigma^2_component = 0, testing k vs k+1 mixture components): -2 log Lambda is NOT chi^2_r -- it is a mixture (e.g. 0.5 chi^2_0 + 0.5 chi^2_1) or has an even more complex limit. Using chi^2_r is conservative here.
- **drop `log_likelihood_smooth`:** non-regular models (uniform endpoint): -2 log Lambda has a non-chi^2 limit (often exponential-related)
- **drop `nested_and_smooth_Theta_0`:** if Theta_0 is not a smooth submanifold (e.g. a single point in a curved family, or a non-identified restriction) the df count d - r can be wrong

## wald_test

- **spec:** scalar: W = (theta_hat - theta_0)^2 / se^2 = (z-statistic)^2 -- the squared 'estimate over standard error'
- **spec:** the z-values printed next to GLM coefficients ARE Wald tests of H0: beta_j = 0
- **spec:** for a linear model with normal errors the Wald test of several coefficients is exactly q F_{q, n-p} rescaled
- **drop `reparametrization`:** testing H0: theta = 1 vs H0: log theta = 0 gives DIFFERENT Wald statistics and p-values though the hypotheses are identical -- the Wald test is not invariant. The LRT and score test are.
- **drop `true_parameter_interior`:** the 'Hauck-Donner effect': for a logistic coefficient far from 0 with a large SE, W can DECREASE as the effect grows, so the Wald test loses power exactly when the effect is large. Use the LRT.
- **drop `fisher_information_positive_definite`:** near-singular information (collinearity) makes W numerically unstable

## score_test

- **spec:** Pearson's chi-squared goodness-of-fit statistic IS the score test for the multinomial (pearson_chi_squared_gof)
- **spec:** the Breusch-Pagan test for heteroskedasticity and the Breusch-Godfrey test for autocorrelation are score (LM) tests
- **spec:** testing whether to add a variable to a regression: the score test needs only the model WITHOUT it -- efficient for variable screening
- **drop `fisher_information_positive_definite`:** singular I(theta_0) (a redundant restriction) makes the inverse undefined
- **drop `H0_regular`:** if theta_0 is on the boundary the score does not have mean 0 in the two-sided sense and the chi^2 calibration fails

## three_tests_asymptotically_equivalent

- **spec:** scalar linear-normal case: all three reduce EXACTLY (not just asymptotically) to the t^2 / F statistic
- **spec:** for a proportion: Wald uses p_hat(1-p_hat), score uses p_0(1-p_0) -- the score (Wilson) test/interval has far better small-sample coverage though they agree in the limit
- **spec:** ordering in finite samples is problem-dependent, but often -2 log Lambda is between W and S
- **drop `regularity_all_three`:** at a boundary or in a non-regular model the three can have DIFFERENT (non-chi^2) limits and are no longer equivalent
- **drop `far_from_local`:** against a FIXED (non-local) alternative all three have power -> 1 but at different rates; 'equivalent' is a local statement

## p_value

- **spec:** one-sample t-test: p = 2 P(t_{n-1} >= |t_obs|)
- **spec:** a p-value of 0.03 means: IF H0 held, data this extreme or more would occur 3% of the time
- **spec:** the p-value curve over candidate null values traces out (one minus) the confidence-interval coverage -- p > alpha exactly for theta_0 in the 1 - alpha CI
- **drop `simple_null_or_sup_taken`:** with a composite null and a non-pivotal statistic the sup is intractable; one uses a plug-in or a similar test, and the p-value is only approximately calibrated
- **drop `T_continuous`:** for discrete data the p-value is not Uniform under H0 -- it is stochastically larger (the test is conservative)

## p_value_uniform_under_null

- **spec:** a histogram of p-values across many true nulls should look flat -- a spike near 0 signals real effects, a spike near 1 signals a misspecified (conservative) test or dependence
- **spec:** under the ALTERNATIVE, the p-value distribution is stochastically smaller than Uniform (concentrated near 0), and more so with higher power
- **spec:** discrete T: p(X) is stochastically LARGER than Uniform -- P(p <= alpha) < alpha, the test is conservative
- **drop `T_continuous`:** binomial / Poisson / permutation tests with few distinct values: the p-value takes finitely many values and P(p <= alpha) jumps below alpha -- 'mid-p' or randomized p-values restore uniformity
- **drop `H0_simple`:** with a composite null the p-value defined via the sup is Uniform at the least-favorable null point and stochastically larger elsewhere

## pearson_chi_squared_gof

- **spec:** testing a fully specified distribution (d = 0): df = k - 1
- **spec:** test of independence in an r x c table: d = (r-1) + (c-1) estimated margins, df = (r-1)(c-1)
- **spec:** rule of thumb: valid when all E_j >= 5 (else exact / Monte Carlo tests)
- **drop `parameters_estimated_efficiently_AND_from_grouped_data`:** if theta is estimated from the RAW (ungrouped) data rather than the cell counts, the limiting distribution is BETWEEN chi^2_{k-1-d} and chi^2_{k-1} (Chernoff-Lehmann) -- using chi^2_{k-1-d} then over-rejects
- **drop `large_expected_counts`:** sparse tables (many E_j < 5): the chi^2 approximation fails; the statistic is not chi^2 and can be wildly miscalibrated

## multiple_testing_fwer

- **spec:** m = 20 independent tests at 0.05 each: FWER approx 1 - 0.95^20 = 0.64 -- a coin flip that SOMETHING is 'significant'
- **spec:** FWER control is appropriate when even one false claim is costly (a drug's primary + key secondary endpoints)
- **spec:** for large-scale screening (genomics) FWER is too strict and FDR is used instead
- **drop `the_family_is_well_defined`:** if the analyst does not fix the family in advance, the 'number of tests' is ambiguous and any correction is gameable -- the multiplicity problem is really a pre-registration problem

## bonferroni_correction

- **spec:** Holm's step-down procedure uniformly improves on Bonferroni at no cost (also FWER, any dependence) -- always prefer it
- **spec:** m = 2 (co-primary endpoints): test each at 0.025
- **spec:** for POSITIVELY dependent tests Bonferroni is conservative; Sidak (1 - (1-alpha)^{1/m}) is slightly tighter under independence
- **drop `none_all_hypotheses_essential`:** the bound holds unconditionally; its weakness is conservatism (low power) when m is large or tests are positively dependent, not invalidity

## benjamini_hochberg_fdr

- **spec:** m = 100, alpha = 0.05, if 10 p-values are below 0.005: BH rejects them -- expected ~0.5 false among the 10
- **spec:** the adaptive (Storey) version estimates m_0 and is less conservative
- **spec:** q-values (Storey) are the FDR analogue of p-values -- the minimum FDR at which a given test is called significant
- **drop `independence_or_PRDS`:** under arbitrary (e.g. negative) dependence the plain BH procedure can exceed alpha; the Benjamini-Yekutieli correction divides alpha by sum_{i=1}^m 1/i (~ log m), restoring control at a power cost
- **drop `many_true_nulls`:** if m_0 = m (all null) FDR control coincides with weak FWER control -- BH does not waste power there

## empirical_cdf

- **spec:** F_hat_n(x) -> F(x) a.s. pointwise (SLLN) and uniformly (Glivenko-Cantelli)
- **spec:** sqrt(n)(F_hat_n(x) - F(x)) -> N(0, F(x)(1-F(x))) pointwise (CLT), -> a Brownian bridge as a process (Donsker)
- **spec:** the inverse F_hat_n^{-1} gives sample quantiles
- **drop `none_all_hypotheses_essential`:** the ECDF is defined for any sample; its consistency (Glivenko-Cantelli) needs only iid -- no moment or smoothness assumption

## order_statistic

- **spec:** X_(n) for uniform(0, theta): the sufficient statistic and (after bias correction) the UMVUE of theta
- **spec:** F(X_(k)) ~ Beta(k, n-k+1): distribution-free, the basis of nonparametric quantile confidence intervals
- **spec:** the range X_(n) - X_(1) and the interquartile range are functions of order statistics
- **drop `continuous_parent_for_the_clean_Beta_result`:** with ties (discrete data) the Beta-distribution results for F(X_(k)) fail; mid-rank corrections are needed

## sample_quantile

- **spec:** sample median of iid N(mu, sigma^2): sqrt(n)(median - mu) -> N(0, pi sigma^2 / 2) -- asymptotic variance pi/2 times that of Xbar (ARE 2/pi, relative_efficiency)
- **spec:** distribution-free CI for Q(p): [X_(r), X_(s)] with r, s from the Binomial(n, p) quantiles -- exact coverage, no density needed
- **spec:** the sample quantile function traced over p is the Q-Q-plot ordinate
- **drop `positive_density_at_the_quantile`:** if f(Q(p)) = 0 (a gap in the support, or estimating an extreme quantile p -> 0) the sqrt(n)-normal limit fails -- the rate and shape change
- **drop `unique_quantile`:** a flat stretch of F at level p makes Q(p) an interval; the sample quantile is unstable there

## glivenko_cantelli

- **spec:** justifies the plug-in principle: T(F_hat_n) -> T(F) for any sup-norm-continuous functional T
- **spec:** the basis of the bootstrap's first-order validity (resampling from F_hat_n approximates resampling from F)
- **spec:** generalizes to VC classes (Vapnik-Chervonenkis): uniform convergence over any class of sets with finite VC dimension -- the foundation of statistical learning theory
- **drop `iid`:** for dependent data (a time series) F_hat_n still converges pointwise under ergodicity but the uniform / rate results need mixing conditions
- **drop `the_class_is_not_too_rich`:** uniform convergence FAILS over an arbitrary class of sets -- e.g. over all finite sets, sup |P_hat_n(A) - P(A)| = 1 always (A = the sample). Half-lines (VC dim 1) are simple enough; this is why VC dimension matters.

## dvoretzky_kiefer_wolfowitz

- **spec:** n = 100, alpha = 0.05: eps_n approx 0.136 -- a band +-0.136 around F_hat_n contains the entire true F with 95% confidence
- **spec:** gives a conservative distribution-free Kolmogorov-Smirnov critical value (the exact KS null is slightly tighter)
- **spec:** sample size for a band of half-width eps: n = log(2/alpha) / (2 eps^2)
- **drop `iid`:** for dependent data the exponential rate degrades; block or spectral corrections are needed
- **drop `the_2_constant`:** the pre-Massart bound had a larger constant; using exp(-2nt^2) without the factor 2 in front slightly undercovers for the two-sided band

## plug_in_estimator

- **spec:** T(P) = E_P[X] => plug-in Xbar, IF(x) = x - mu
- **spec:** T(P) = Var_P(X) => plug-in the /n sample variance, IF(x) = (x - mu)^2 - sigma^2
- **spec:** T(P) = median => plug-in sample median, IF(x) = (1/2 - 1{x <= m}) / f(m) -- note the density in the denominator
- **drop `Hadamard_differentiability`:** T(P) = f_P(x_0) (a density value) or T(P) = number of modes: not a differentiable functional; the plug-in either does not exist (density of a discrete P_hat_n) or converges at a slower nonparametric rate
- **drop `IF_has_finite_variance`:** if E[IF(X)^2] = inf (heavy tails and a functional sensitive to them) the sqrt(n) normal limit fails

## bootstrap

- **spec:** bootstrap SE: the sample standard deviation of the B values T_n*
- **spec:** percentile CI: the alpha/2 and 1 - alpha/2 empirical quantiles of the T_n* -- simple but first-order; BCa and bootstrap-t are second-order accurate
- **spec:** the parametric bootstrap resamples from F(.; theta_hat) instead of P_hat_n -- useful when a model is trusted
- **drop `smooth_functional`:** the maximum of a uniform(0, theta) sample: the bootstrap distribution of n(theta_hat - theta_hat*) does NOT converge to the true Exponential limit -- P(X_(n)* = X_(n)) -> 1 - 1/e, an atom that should not be there. The m-out-of-n bootstrap or subsampling fixes it.
- **drop `limit_free_of_nuisance`:** bootstrapping a non-studentized statistic when the limit variance is unknown gives poor coverage -- bootstrap the STUDENTIZED (pivotal) statistic (bootstrap-t)

## bootstrap_consistency

- **spec:** smooth functions of sample moments (correlation, R^2, ratio of means): bootstrap-consistent under moment conditions
- **spec:** the bootstrap-t (studentized) interval has coverage 1 - alpha + O(1/n) -- one order better than the normal approximation's O(1/sqrt n)
- **spec:** empirical-process functionals (KS statistic, Cramer-von Mises): bootstrap-consistent (Donsker class)
- **drop `Hadamard_differentiability`:** the sample maximum / extreme quantiles (not differentiable), a parameter on the boundary of the space, the number of components in a mixture -- the ordinary n-out-of-n bootstrap is INCONSISTENT; subsampling or m-out-of-n is needed
- **drop `nondegenerate_influence_function`:** at a point where IF = 0 (e.g. g(theta_hat) with g'(theta) = 0) the sqrt(n) scaling is wrong and the bootstrap distribution degenerates
- **drop `iid`:** the ordinary bootstrap is inconsistent for dependent data -- block bootstrap under mixing

## kernel_density_estimator

- **spec:** h -> 0 with n h -> inf: f_hat_h(x) -> f(x) in probability at each continuity point
- **spec:** the choice of K barely matters (efficiency within a few %); the choice of h matters enormously
- **spec:** multivariate KDE suffers the curse of dimensionality -- the rate degrades to n^{-2/(4+d)}
- **drop `h_chosen_well`:** h too small: f_hat is a spiky mess (n bumps); h too large: f_hat is oversmoothed and hides real features (bimodality). There is no h that is right everywhere if f has varying curvature -- adaptive bandwidths address this.
- **drop `f_smooth`:** if f has a discontinuity or a kink (uniform density's edges, an exponential at 0) the KDE smears it and the bias there is O(1), not O(h^2) -- boundary bias

## kde_bias_variance_tradeoff

- **spec:** the same 2nd-order-vs-4th-order rate logic governs local polynomial regression, spline smoothing, and every nonparametric-regression method
- **spec:** higher-order kernels (allowing negative lobes) push the bias to O(h^4) and the rate to n^{-8/9} -- at the cost of a possibly-negative density estimate
- **spec:** d dimensions: h ~ n^{-1/(4+d)}, MISE ~ n^{-4/(4+d)} -- the curse of dimensionality
- **drop `f_twice_differentiable`:** if f is only Lipschitz (one derivative) the best rate drops to n^{-2/3}; if f has a jump, to n^{-1/2} away from the jump and O(1) at it
- **drop `interior_x`:** at the boundary of the support the bias is O(h) not O(h^2) unless a boundary kernel is used -- boundary bias dominates the MISE if untreated

## linear_model

- **spec:** simple linear regression: p = 2, X columns (1, x_i)
- **spec:** polynomial / spline / dummy-variable regression: still linear IN beta, X holds the transformed features
- **spec:** one-way ANOVA is the linear model with X a matrix of group indicators
- **drop `full_column_rank`:** exact collinearity (a redundant dummy, x_2 = 2 x_1): X^T X is singular, beta is not identified, OLS has no unique solution
- **drop `errors_uncorrelated_homoskedastic`:** heteroskedasticity or autocorrelation: OLS stays unbiased but is no longer BLUE and the usual SEs are wrong (need GLS or robust SEs)
- **drop `gaussian_errors`:** only needed for EXACT t / F inference; drop it and the t/F statistics are asymptotically valid by the CLT (if n - p is large and the design is not too leveraged)

## ordinary_least_squares

- **spec:** p = 1, no intercept: beta_hat = sum x_i y_i / sum x_i^2
- **spec:** simple regression: slope = Cov_hat(x, y)/Var_hat(x), intercept = ybar - slope xbar
- **spec:** OLS = MLE of beta under eps ~ N(0, sigma^2 I) (maximizing the Gaussian likelihood minimizes the SSE)
- **drop `full_rank_X`:** collinear X: the argmin is a whole affine subspace; OLS is undefined (ridge / pseudoinverse picks the minimum-norm solution)

## normal_equations

- **spec:** orthogonal design (X^T X diagonal): beta_hat_j = (x_j^T y)/(x_j^T x_j) -- each coefficient is a separate simple regression
- **spec:** adding a column orthogonal to the existing ones does not change the existing coefficients (Frisch-Waugh, partitioned_regression)
- **spec:** centered predictors: the intercept decouples as ybar
- **drop `X_full_rank`:** singular X^T X (collinearity): the normal equations have infinitely many solutions; the fitted values X beta_hat are still unique (the projection), but the coefficients are not

## ols_is_projection

- **spec:** one predictor = the constant: H = (1/n) J, y_hat_i = ybar for all i -- 'regression on an intercept' is just the mean
- **spec:** leverage h_ii in [1/n, 1]; h_ii > 2p/n flags a high-leverage point
- **spec:** the Pythagorean decomposition ||y||^2 = ||Hy||^2 + ||(I-H)y||^2 is the ANOVA / R^2 identity
- **drop `X_full_rank`:** rank-deficient X: H is still the (unique) projector onto col(X), of rank rank(X) < p; beta_hat is non-unique but y_hat = Hy is unique

## residual_sum_of_squares

- **spec:** RSS is nonincreasing as predictors are added (more columns can only reduce the projection residual) -- why RSS alone cannot select a model
- **spec:** RSS/(n-p) = sigma_hat^2, the unbiased error-variance estimate
- **spec:** the F-test compares RSS of nested models: (RSS_0 - RSS)/(RSS/(n-p))
- **drop `gaussian_errors_for_the_chi2_law`:** non-normal errors: E[RSS] = (n-p) sigma^2 still holds (it is a trace identity), but RSS/sigma^2 is not chi^2_{n-p}
- **drop `correct_mean_model`:** if E[y] is not X beta (omitted nonlinearity) then E[RSS] > (n-p) sigma^2 -- RSS is inflated by the model bias (the basis of the lack-of-fit F-test)

## unbiased_error_variance_estimator

- **spec:** p = 1 (intercept only): n - p = n - 1, recovers S^2 (bias_of_sample_variance)
- **spec:** sigma_hat = sqrt(sigma_hat^2) is the 'residual standard error' printed in every regression summary
- **spec:** the SEs of the coefficients are sigma_hat sqrt( ((X^T X)^{-1})_jj )
- **drop `Cov(eps) = sigma^2 I`:** heteroskedastic or autocorrelated errors: E[RSS/(n-p)] != sigma^2 (there is no single sigma^2); the model-based SEs are wrong -- use White / Newey-West robust SEs
- **drop `correct_mean_model`:** omitted nonlinearity inflates RSS, so sigma_hat^2 is biased UP -- the lack-of-fit test exploits this

## gauss_markov_theorem

- **spec:** OLS is BLUE even for heavy-tailed (finite-variance) errors -- normality is NOT needed for this
- **spec:** with normal errors, OLS is additionally the MVUE among ALL unbiased estimators (not just linear), and is the MLE
- **spec:** if Cov(eps) = sigma^2 V (known V != I): GLS beta_hat_GLS = (X^T V^{-1} X)^{-1} X^T V^{-1} y is BLUE, and OLS is no longer efficient
- **drop `Cov(eps) = sigma^2 I`:** heteroskedasticity (Cov(eps) = diag(sigma_i^2)): OLS is still unbiased but NOT BLUE -- weighted least squares with weights 1/sigma_i^2 beats it; and OLS's usual SEs are wrong
- **drop `autocorrelated errors (time series)`:** OLS inefficient; GLS / Cochrane-Orcutt or Newey-West SEs needed
- **drop `linearity_and_correct_mean`:** if E[y] != X beta, OLS is biased and 'BLUE' is moot

## ols_distribution_under_normal_errors

- **spec:** p = 1, X = 1: beta_hat = Xbar ~ N(mu, sigma^2/n), RSS/sigma^2 ~ chi^2_{n-1} -- exactly the one-sample normal results
- **spec:** the coefficient t-statistic (beta_hat_j - beta_j)/(sigma_hat sqrt((X^TX)^{-1}_jj)) ~ t_{n-p} exactly (coefficient_t_test)
- **spec:** a linear-hypothesis F-statistic ~ F_{q, n-p} exactly (overall_f_test)
- **drop `gaussian_errors`:** non-normal errors: beta_hat is only ASYMPTOTICALLY normal (CLT for (X^T X)^{-1} X^T eps, valid if no single row of X dominates -- max leverage h_ii -> 0); RSS/sigma^2 is not chi^2; the t/F p-values are approximate
- **drop `homoskedastic_uncorrelated`:** Cov(eps) = sigma^2 V != sigma^2 I: beta_hat ~ N(beta, sigma^2 (X^TX)^{-1} X^T V X (X^TX)^{-1}) -- the 'sandwich' covariance; the naive (X^TX)^{-1} SEs are wrong

## coefficient_t_test

- **spec:** the 't value' and 'Pr(>|t|)' columns of every regression summary table
- **spec:** one predictor of interest, others as controls: t_j tests the PARTIAL effect (holding the other X fixed) -- Frisch-Waugh (partitioned_regression)
- **spec:** as n - p grows, t_{n-p} -> N(0,1) and the t-test approaches the Wald z-test
- **drop `gaussian_errors`:** with non-normal errors the exact t_{n-p} calibration is lost; for large n - p and bounded leverage it is asymptotically valid (t -> N(0,1) via the CLT for beta_hat)
- **drop `homoskedasticity`:** heteroskedastic errors make se(beta_hat_j) wrong -- use HC (White) robust SEs; the point estimate beta_hat_j stays unbiased
- **drop `no_collinearity`:** near-collinear predictors inflate ((X^TX)^{-1})_jj (the variance inflation factor), giving large SEs and unstable, individually-non-significant coefficients even when the group is jointly significant

## overall_f_test

- **spec:** q = 1: F_{1, n-p} = (t_{n-p})^2 -- the F-test of one coefficient is the square of its t-test
- **spec:** overall F (all slopes 0): F = [ (TSS - RSS)/(p-1) ] / [ RSS/(n-p) ] = [R^2/(p-1)] / [(1-R^2)/(n-p)]
- **spec:** nested model comparison / analysis of variance / ANCOVA all use this statistic
- **drop `gaussian_errors`:** non-normal errors: F is only asymptotically q^{-1} chi^2_q (i.e. approximately F); robust or bootstrap versions exist
- **drop `the_restriction_is_linear_and_pre-specified`:** a data-driven restriction (testing the predictors that looked promising) invalidates the F null distribution -- selective inference
- **drop `homoskedasticity`:** heteroskedasticity distorts the F null distribution; use a heteroskedasticity-robust Wald test of R beta = r

## r_squared

- **spec:** simple regression: R^2 = (sample correlation of x and y)^2
- **spec:** R^2 = 0: the model does no better than ybar; R^2 = 1: exact fit (residuals all 0)
- **spec:** in-sample R^2 vs cross-validated / out-of-sample R^2 -- the gap measures overfitting
- **drop `model_has_an_intercept`:** without an intercept the identity TSS = explained + RSS fails and 'R^2' can be negative or > 1 depending on the software's convention -- it is not interpretable
- **drop `same_response_and_no_transformation`:** R^2 for a model of y and a model of log y are not comparable; a high R^2 can accompany a badly misspecified model and a low R^2 a correct one (just noisy)

## partitioned_regression

- **spec:** time-series regression with a trend: 'detrend y and x, then regress' gives the same slope as including the trend
- **spec:** fixed-effects panel estimator = regress the within-group-demeaned y on the within-group-demeaned x (X_1 = the group dummies)
- **spec:** the residuals from the full regression equal the residuals from the partialled-out simple regression
- **drop `X_1_and_X_2_not_collinear`:** if X_2 lies in the span of X_1 then M_1 X_2 = 0 and beta_hat_2 is not identified -- 'controlling for X_1' has removed all variation in X_2

## likelihood_principle

- **spec:** binomial vs negative-binomial sampling giving the same observed (successes, failures): the likelihoods are proportional, so a likelihoodist / Bayesian analysis is identical -- but the frequentist p-value DIFFERS (different sample spaces)
- **spec:** sequential trials: under the likelihood principle, 'we stopped when it looked significant' does not change the evidence in the observed data -- diametrically opposed to frequentist alpha-spending
- **spec:** fully obeyed by Bayesian posteriors and by pure-likelihood (Royall) inference
- **drop `accepting_both_premises_unrestrictedly`:** the principle is CONTESTED. Frequentists reject it (or reject one of Birnbaum's premises) precisely because it outlaws pre-data error-rate control; Mayo (2014) and others dispute the theorem's premises. This node states the principle and the theorem; it does not adjudicate.

## sufficiency_principle

- **spec:** obeyed by MLE, Bayes, UMVUE, LRT -- all are functions of any sufficient statistic
- **spec:** the basis for reducing a whole sample to (Xbar, S^2) in normal-theory inference with no loss
- **drop `none_all_hypotheses_essential`:** the principle is a stance; there is nothing to 'drop'. A method violating it (e.g. one depending on the order in which iid data arrived) would be regarded as defective.

## conditionality_principle

- **spec:** the classic example (Cox 1958): a measurement is made by a randomly chosen instrument of known, different precisions -- report the SE of the instrument used, not a mixture SE
- **spec:** conditioning on the observed information (rather than expected) in likelihood inference is a conditionality-principle move (Efron-Hinkley)
- **spec:** conditioning on ancillary configuration statistics in location-scale models -> exact conditional inference (Fisher, Fraser)
- **drop `the_selector_is_ancillary`:** if which 'experiment' is run depends on theta (informative sampling, response-adaptive designs), conditioning on it can bias the analysis -- the principle applies only to theta-ancillary selection

## le_cam_lan_theory

- **spec:** MLE asymptotic normality, Wilks' theorem, and the asymptotic equivalence of the Wald/score/LR tests are all corollaries of LAN + properties of the Gaussian shift experiment
- **spec:** contiguity (Le Cam's lemmas) lets you compute limiting power under alternatives from behaviour under the null
- **spec:** semiparametric efficiency theory (LAN with an infinite-dimensional nuisance) generalizes it
- **drop `regular_model`:** non-LAN models: uniform(0, theta) is locally asymptotically EXPONENTIAL (LAE, rate n); some models are locally asymptotically MIXED normal (LAMN, e.g. explosive AR, some diffusions). The Gaussian-shift reduction and its optimality conclusions do not apply.
- **drop `fixed_dimension`:** increasing-dimension / nonparametric models need the infinite-dimensional LAN theory and have their own (slower) efficiency bounds

## hajek_convolution_theorem

- **spec:** the MLE (M = delta_0) is efficient; a regular but inefficient estimator has M nondegenerate, i.e. strictly more spread
- **spec:** removes the Hodges superefficiency loophole: superefficient estimators are NOT regular (their local limit law depends on h)
- **spec:** the semiparametric analogue bounds regular estimators of a finite-dimensional functional in a model with an infinite-dimensional nuisance
- **drop `regularity_of_the_estimator`:** drop it and Hodges' estimator formally 'beats' I^{-1} at a point -- but only by being non-regular (badly behaved just off that point), which the theorem's hypothesis excludes
- **drop `LAN_model`:** in LAMN models the bound involves a random information and the statement changes (mixed-normal limits)

## local_asymptotic_minimax

- **spec:** squared-error loss: the local minimax risk bound is tr(I(theta_0)^{-1}), matched by the MLE
- **spec:** Hodges' superefficient estimator: efficient at theta_0 but its local minimax risk over |h| <= c tends to infinity as c grows -- superefficiency is paid for by terrible risk nearby
- **spec:** the semiparametric LAM bound governs efficient estimation of a functional in the presence of a nonparametric nuisance
- **drop `bowl_shaped_loss`:** for non-bowl-shaped (asymmetric) loss the bound changes and Anderson's lemma does not apply directly
- **drop `LAN`:** non-regular models have their own (different, often faster or slower) minimax rates -- see minimax_rate

## donsker_theorem

- **spec:** sup_x |G_n(x)| -> sup |Brownian bridge| gives the Kolmogorov-Smirnov limiting distribution (Kolmogorov's formula)
- **spec:** int G_n^2 dF -> int (Brownian bridge)^2 gives the Cramer-von Mises limit
- **spec:** the functional delta method: for Hadamard-differentiable T, sqrt(n)(T(F_hat_n) - T(F)) -> T'_F(G) -- the source of asymptotic normality for quantiles, trimmed means, L-statistics, and the bootstrap's validity
- **drop `Donsker_class`:** the class of ALL indicator functions of finite sets is not Donsker -- and neither is a class with infinite uniform entropy; over such classes the empirical process does not converge (it is not even tight). This is what separates 'nice' nonparametric problems from genuinely hard ones.
- **drop `iid`:** dependent data need mixing conditions and give a different (long-range vs short-range) limit

## minimax_rate

- **spec:** density estimation, twice-differentiable (beta = 2), d = 1: rate n^{-4/5} -- matches the KDE MISE (kde_bias_variance_tradeoff)
- **spec:** nonparametric regression with beta-smooth mean, d covariates: n^{-2 beta/(2 beta + d)}
- **spec:** d = 10, beta = 2: rate n^{-4/14} approx n^{-0.29} -- to halve the error you need ~11x the data (the curse of dimensionality); this is why structure (additivity, sparsity, single-index) is imposed
- **drop `the_smoothness_class_is_correct`:** if f is actually rougher than assumed (fewer derivatives) the tuned estimator is inconsistent at the claimed rate; adaptive estimators (Lepski, wavelet thresholding) achieve the right rate WITHOUT knowing beta, at a log-factor cost
- **drop `no_extra_structure`:** under sparsity or a low-dimensional structure the effective d is much smaller and near-parametric rates return -- the entire premise of high-dimensional statistics
