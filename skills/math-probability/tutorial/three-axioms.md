# Three axioms, and everything before random variables

> Generated from the `math-probability` capsule (Release 0.1) with the
> `theorem-tree-tutorial` skill. The mathematics, the prerequisite order, and
> every calculation and proof come from that capsule —
> `validation/proof-checks.lean` and each result's YAML entry in particular.

Probability theory is three sentences (`P ≥ 0`, `P(Ω) = 1`, countable
additivity) plus the σ-algebra they live on. Before you ever meet a random
variable, those three sentences already force the complement rule, monotonicity,
finite additivity, and the **union bound** — the single most-used inequality in
the subject. This tutorial walks that closure on one object: **a fair
six-sided die**, `Ω = {1,2,3,4,5,6}` with `P({k}) = 1/6`. Each theorem you meet
comes with a check that it holds on the die, then a check that it **breaks** the
moment a hypothesis is dropped.

## How to run this

Install [`upmd`](https://upmd.dev), then from the repository root:

- `upmd skills/math-probability/tutorial/three-axioms.md` — the interactive walk.
- `upmd --ci --all skills/math-probability/tutorial/three-axioms.md` — run every
  check top to bottom (the verification gate).
- `upmd --ci -b capstone skills/math-probability/tutorial/three-axioms.md` — the
  final verdict and everything it depends on.

Each section ends with block(s) you run; blocks `deps:` earlier ones in the same
partial order as the capsule's graph, so `upmd --ci -b chk_boole_inequality …`
runs one check with its whole chain. The `lean_…` blocks call the Lean 4 kernel
through a shell wrapper (`upmd` has no native Lean runner); if `lean` is not on
your `PATH` they print `SKIP` and still exit 0.

Set operations — union, intersection, complement, De Morgan — and the idea of a
**countable** family; the real interval `[0,1]`. These come from
[`math-sets-functions-cardinality`](../../math-sets-functions-cardinality/SKILL.md)
and [`math-real-analysis`](../../math-real-analysis/SKILL.md); here they are used,
not rebuilt. Every result below is `choice_free` and `constructive` — the
capsule tags each one, and nothing in this slice needs the Axiom of Choice or
excluded middle.

## 0. Setup

The die, as integer counts out of 6. Every later block recomputes from these.

```bash [name:setup]
export OMEGA_N=6                 # |Omega| = 6 outcomes, each of probability 1/6
export SCEN="fair six-sided die, Omega = {1..6}, P({k}) = 1/6"
echo "worked object: $SCEN"
```

## 1. The σ-algebra — which sets get a probability

**`sigma_algebra`**: a family `F` of subsets of `Ω` with `Ω ∈ F`, closed under
complement, and closed under **countable** unions (hence countable
intersections). The pair `(Ω, F)` is all the structure a measure needs.
Closure is under *countable* unions, not arbitrary ones — that is the whole
subtlety of the definition, and the reason `F` can be strictly smaller than
`2^Ω` when `Ω` is uncountable. For a finite `Ω` the honest and universal choice
is `F = 2^Ω`: every subset is an event. The check below verifies the three
axioms on the two extreme σ-algebras over `Ω = {1,2,3}`, and confirms that an
**intersection** of σ-algebras is again one — the fact that makes "the smallest
σ-algebra containing `C`" well-defined. *(Billingsley §2; Folland §1.)*

```bash [name:chk_sigma_algebra, deps:setup]
# sets over {1,2,3} as 3-bit membership strings, bit k = "k is in the set"
compl () { echo "$1" | tr '01' '10'; }
uni ()  { printf '%d%d%d' $(( ${1:0:1}|${2:0:1} )) $(( ${1:1:1}|${2:1:1} )) $(( ${1:2:1}|${2:2:1} )); }

# F1 = {emptyset, Omega}
empty=000; omega=111
echo "trivial F = { $empty , $omega }:"
echo "  Omega in F                : yes"
echo "  complement of $empty       : $(compl $empty)  (= Omega, in F)"
echo "  complement of $omega       : $(compl $omega)  (= emptyset, in F)"
echo "  $empty union $omega          : $(uni $empty $omega)  (= Omega, in F)   -> sigma-algebra OK"

# intersection of two sigma-algebras over {1,2,3}
#   F_a = { 000, 100, 011, 111 }   (generated by {1})
#   F_b = { 000, 110, 001, 111 }   (generated by {3})
fa="000 100 011 111"; fb="000 110 001 111"
inter=""
for x in $fa; do case " $fb " in *" $x "*) inter="$inter $x";; esac; done
echo
echo "F_a cap F_b = {$inter } = { emptyset, Omega }  -> still a sigma-algebra"
[ "$(echo $inter)" = "000 111" ] || { echo "FAIL: intersection wrong"; exit 1; }
```

The output shows both extremes pass and the intersection collapses to `{∅,Ω}` —
itself a σ-algebra.

```bash [name:cx_sigma_algebra, deps:chk_sigma_algebra]
# drop countable-union closure: the finite-or-cofinite subsets of N.
# each {2},{4},{6},... is FINITE, so in the family. Their union is the evens.
n=200
# is "evens up to n" finite?  no, it grows without bound as n -> infinity
# is its complement (the odds) finite?  also no.
evens_card=$(( n / 2 ))
odds_card=$(( n - n / 2 ))
echo "union of {2},{4},...,{$n} has $evens_card elements (grows forever: not finite)"
echo "its complement (the odds) has $odds_card elements               (also not finite)"
echo "=> the evens are neither finite nor cofinite => NOT in the family"
echo "the finite/cofinite family is closed under complement and FINITE unions,"
echo "but a countable union escaped it. It is an algebra, not a sigma-algebra."
[ "$evens_card" -gt 10 ] && [ "$odds_card" -gt 10 ] || { echo "FAIL"; exit 1; }
```

## 2. The measurable space

**`measurable_space`**: just the pair `(Ω, F)` — a set and a σ-algebra on it. No
probabilities yet. It is the *domain* on which a measure will be defined; the
morphisms between measurable spaces are the measurable functions (§ not covered
here). For the die, `(Ω, 2^Ω)`. The only thing to get wrong is to conflate it
with the **probability space** `(Ω, F, P)`, which adds `P`. *(Billingsley §2.)*

```bash [name:chk_measurable_space, deps:chk_sigma_algebra]
echo "measurable space for the die : ( {1..6} , 2^{1..6} )"
echo "  2^Omega has $(( 2 ** OMEGA_N )) members -- every subset is an event"
echo "  no measure attached yet: this is the stage, not the play"
```

## 3. The measure

**`measure`**: a function `μ : F → [0,∞]` with `μ(∅) = 0` that is **countably
additive** — for a *countable* disjoint family `A_1, A_2, …`,
`μ(⋃ A_n) = Σ μ(A_n)`. Counting measure (`μ(A) = |A|`), Lebesgue measure, and a
point mass `δ_x` are the standard examples. Countable additivity — not merely
finite additivity — is the load-bearing clause; drop it and continuity of the
measure and the Borel–Cantelli lemmas all fail. The check runs counting measure
on the die's outcome set and verifies additivity across the partition
`{1,2} ⊔ {3,4} ⊔ {5,6}`; the counterexample shows a *finitely* additive set
function that is not a measure. *(Billingsley §10; Folland §1.3.)*

```bash [name:chk_measure, deps:"chk_measurable_space | chk_sigma_algebra"]
# counting measure on {1..6}:  mu(A) = |A|
mu_empty=0
mu_12=2; mu_34=2; mu_56=2
mu_union=$(( mu_12 + mu_34 + mu_56 ))
echo "mu(emptyset)              = $mu_empty            (want 0)"
echo "mu({1,2})+mu({3,4})+mu({5,6}) = $mu_union"
echo "mu({1,2,3,4,5,6})            = $OMEGA_N            (want $mu_union -- countable additivity)"
[ "$mu_empty" = 0 ] && [ "$mu_union" = "$OMEGA_N" ] || { echo "FAIL"; exit 1; }
```

```bash [name:cx_measure, deps:chk_measure]
# drop countable additivity: on Omega = N, F = 2^N, set
#   nu(A) = 0 if A finite,  nu(A) = 1 if A cofinite.
# finitely additive and nu(N) = 1, but:
echo "nu({k}) = 0 for every single k  (each singleton is finite)"
sum_singletons=0                       # sum over all k of nu({k}) = 0 + 0 + ...
echo "sum_k nu({k})            = $sum_singletons"
echo "nu( union_k {k} ) = nu(N) = 1"
echo "0  !=  1   => nu is NOT countably additive => nu is not a measure."
echo "(this is exactly why Kolmogorov's third axiom is COUNTABLE, not finite.)"
[ "$sum_singletons" -ne 1 ] || { echo "FAIL"; exit 1; }
```

## 4. Kolmogorov's axioms

**`kolmogorov_axioms`**: a **probability measure** `P` on `(Ω, F)` is a measure
with `P(Ω) = 1`. Written out: `P(A) ≥ 0`; `P(Ω) = 1`; and for a countable
disjoint family, `P(⋃ A_n) = Σ P(A_n)`. Epistemic status: this is an
**`axiom`** node — the definition probability is built on, not a theorem. Two
things people get wrong: the third axiom is *countable* additivity (finite is a
consequence, §5), and when `Ω` is uncountable `F` cannot be all of `2^Ω`. On a
finite `Ω` a probability measure is just a pmf `p(ω) ≥ 0` summing to 1;
countable additivity is automatic because every sum is finite. *(Kolmogorov
1933; Billingsley §2.)*

```bash [name:chk_kolmogorov_axioms, deps:chk_measure]
# die: pmf p(k) = 1/6. Work in exact SIXTHS -- P(A) as an integer count / 6
# (the "k out of N" convention the capsule's Lean file uses).
p_omega=$(( 1 + 1 + 1 + 1 + 1 + 1 ))          # 6 sixths
echo "P(k) = 1/6 >= 0 for every k              (nonnegativity: yes)"
echo "P(Omega) = 6/6 = $p_omega/6 = 1                  (normalization: want 6/6)"
p_even=3                                       # {2,4,6} = 3 sixths
p_sum=$(( 1 + 1 + 1 ))                         # P(2)+P(4)+P(6)
echo "P({2,4,6}) = $p_even/6  vs  P(2)+P(4)+P(6) = $p_sum/6   (additivity: want equal)"
[ "$p_omega" = 6 ] && [ "$p_even" = "$p_sum" ] || { echo "FAIL"; exit 1; }
```

```bash [name:cx_kolmogorov_axioms, deps:chk_kolmogorov_axioms]
# drop countable additivity, keep the other two: the density on N again.
# nu(A) = 0 (A finite) / 1 (A cofinite) satisfies nu >= 0 and nu(N) = 1 ...
echo "nu >= 0                : yes"
echo "nu(N) = 1              : yes  (N is cofinite in itself)"
echo "nu countably additive : NO -- sum_k nu({k}) = 0  but  nu(union {k}) = nu(N) = 1"
echo
echo "So 'nonnegative + normalized + FINITELY additive' is strictly weaker than a"
echo "probability measure. Every theorem below that needs the countable form"
echo "(continuity of P, Borel-Cantelli) fails for nu."
```

## 5. Finite additivity

**`finite_additivity`**: for pairwise-disjoint `A_1, …, A_n`,
`P(A_1 ∪ … ∪ A_n) = Σ P(A_i)`. It is the finite case of the third axiom — pad
the family with `A_{n+1} = A_{n+2} = … = ∅` (whose probabilities are 0) and
apply countable additivity. `derives_from: kolmogorov_axioms`. The one hypothesis
is **disjointness**; without it the sum double-counts every overlap, and the
correction term is exactly `P(A ∩ B)` (that is inclusion–exclusion). *(Billingsley
§2; Durrett §1.1.)*

```bash [name:chk_finite_additivity, deps:chk_kolmogorov_axioms]
# die, exact sixths: {2,4,6} is a disjoint union of singletons
p_even=3                          # |{2,4,6}| = 3 sixths
p_add=$(( 1 + 1 + 1 ))            # P({2})+P({4})+P({6})
echo "P({2,4,6})         = $p_even/6"
echo "P({2})+P({4})+P({6}) = $p_add/6   (disjoint: want equal)"
[ "$p_even" = "$p_add" ] || { echo "FAIL"; exit 1; }
```

```bash [name:cx_finite_additivity, deps:chk_finite_additivity]
# drop disjointness: A = {1,2,3}, B = {3,4}  overlap in {3}   (exact sixths)
p_a=3; p_b=2                      # |A| = 3, |B| = 2
p_aub=4                           # A cup B = {1,2,3,4}
p_cap=1                           # A cap B = {3}
p_sum=$(( p_a + p_b ))
echo "P(A) + P(B)   = $p_sum/6"
echo "P(A cup B)     = $p_aub/6          (the truth)"
echo "difference    = $(( p_sum - p_aub ))/6  =  P(A cap B) = $p_cap/6"
echo "=> without disjointness the sum overcounts by exactly P(A cap B)."
[ "$(( p_sum - p_aub ))" = "$p_cap" ] || { echo "FAIL"; exit 1; }
```

## 6. Monotonicity and subadditivity of a measure

**`measure_monotonicity`**: `A ⊆ B ⟹ μ(A) ≤ μ(B)`, and `μ` is countably
subadditive: `μ(⋃ A_n) ≤ Σ μ(A_n)` for *any* family. Monotonicity is
`μ(B) = μ(A) + μ(B∖A) ≥ μ(A)`, using `μ ≥ 0`. That last step — **nonnegativity**
— is the hypothesis; for a signed measure a subset can carry more mass than its
superset. `derives_from: measure`. The Lean beat runs the capsule's
kernel-checked core of the subadditive step. *(Billingsley §10; Folland §1.3.)*

```bash [name:chk_measure_monotonicity, deps:chk_measure]
# exact sixths. monotonicity: A = {1,2} subset B = {1,2,3,4}
p_a=2; p_b=4
echo "A = {1,2} subset B = {1,2,3,4}:  P(A) = $p_a/6  <=  P(B) = $p_b/6"
[ "$p_a" -le "$p_b" ] || { echo "FAIL: monotonicity"; exit 1; }
# subadditivity with overlap: A = {1,2,3}, B = {3,4,5}
p_a=3; p_b=3
p_aub=5                                          # {1,2,3,4,5}
echo "P(A cup B) = $p_aub/6  <=  P(A)+P(B) = $(( p_a + p_b ))/6   (strict: they overlap in {3})"
[ "$p_aub" -le "$(( p_a + p_b ))" ] || { echo "FAIL: subadditivity"; exit 1; }
```

```bash [name:lean_measure_monotonicity, deps:setup]
command -v lean >/dev/null || { echo "SKIP: lean not on PATH"; exit 0; }
d=$(mktemp -d)
cat > "$d/ub.lean" <<'LEAN'
-- math-probability/validation/proof-checks.lean, section 1
-- the two-set subadditive core, UNIVERSAL over the integers (genuine, `omega`)
-- P(A) + P(B) - P(A cap B)  <=  P(A) + P(B),  since P(A cap B) >= 0
theorem union_bound (pA pB pAB : Int) (h : 0 <= pAB) :
    pA + pB - pAB <= pA + pB := by omega
LEAN
if lean "$d/ub.lean" 2>/dev/null; then
  echo "kernel accepted, for ALL integers pA, pB, pAB >= 0:"
  echo "  pA + pB - pAB  <=  pA + pB"
  echo "with pAB = P(A cap B) >= 0 this is P(A cup B) <= P(A) + P(B): subadditivity."
else
  echo "FAIL: lean rejected union_bound"; rm -rf "$d"; exit 1
fi
rm -rf "$d"
```

```bash [name:cx_measure_monotonicity, deps:chk_measure_monotonicity]
# drop nonnegativity: a SIGNED measure (in sixths) with nu({5}) = -2
#   A = {1,2}  subset  B = {1,2,5}
nu_a=$(( 1 + 1 ))                 # nu({1}) + nu({2})           =  2/6
nu_b=$(( 1 + 1 + (-2) ))          # nu({1}) + nu({2}) + nu({5}) =  0/6
echo "nu(A) = nu({1,2})   = $nu_a/6"
echo "nu(B) = nu({1,2,5}) = $nu_b/6"
echo "A subset B, yet nu(A) = $nu_a/6  >  nu(B) = $nu_b/6"
echo "=> adding the negative-mass set {5} makes the measure go DOWN. Monotonicity"
echo "   needs nu >= 0."
[ "$nu_a" -gt "$nu_b" ] || { echo "FAIL"; exit 1; }
```

## 7. Boole's inequality — the union bound

**`boole_inequality`**: `P(⋃_n A_n) ≤ Σ_n P(A_n)` for **any** countable family,
disjoint or not. `status_label: proved_theorem`. The proof disjointifies —
`B_n = A_n ∖ (A_1 ∪ … ∪ A_{n-1})`, so `B_n ⊆ A_n`, the `B_n` are disjoint with
the same union, and countable additivity plus monotonicity finish it. There is
**no counterexample**: the bound is unconditional. It is *tight* exactly when the
`A_n` are pairwise disjoint — the boundary case checked below. This one
inequality is what `borel_cantelli_first` and the whole `convergence_implications`
lattice are built on. *(Boucheron–Lugosi–Massart; Durrett §1.6.)*

```bash [name:chk_boole_inequality, deps:"chk_finite_additivity | chk_measure_monotonicity"]
# die, exact sixths: A = {1,2,3}, B = {3,4}, C = {4,5,6}  (A,B overlap in 3; B,C in 4)
p_a=3; p_b=2; p_c=3
p_sum=$(( p_a + p_b + p_c ))                     # 8/6
p_union=6                                        # A cup B cup C = Omega
echo "P(A) + P(B) + P(C)  = $p_sum/6       (= 4/3)"
echo "P(A cup B cup C)     = $p_union/6       (= 1, the truth)"
echo "6/6 <= 8/6  : the union bound holds, and is loose here (lots of overlap)"
[ "$p_union" -le "$p_sum" ] || { echo "FAIL: Boole violated"; exit 1; }
# cross-check against exact inclusion-exclusion: singles - pairs + triple
p_ab=1; p_bc=1; p_ac=0; p_abc=0                  # A∩B={3}, B∩C={4}, A∩C=∅, triple=∅
p_ie=$(( p_sum - (p_ab + p_bc + p_ac) + p_abc ))
echo "inclusion-exclusion : $p_ie/6   (matches P(A cup B cup C))"
[ "$p_ie" = "$p_union" ] || { echo "FAIL: incl-excl mismatch"; exit 1; }
```

```bash [name:lean_boole_inequality, deps:setup]
command -v lean >/dev/null || { echo "SKIP: lean not on PATH"; exit 0; }
d=$(mktemp -d)
cat > "$d/ub.lean" <<'LEAN'
-- math-probability/validation/proof-checks.lean, section 1
-- Prob.union_bound -- the same core as section 6, GENUINE, universal over Int.
theorem union_bound (pA pB pAB : Int) (h : 0 <= pAB) :
    pA + pB - pAB <= pA + pB := by omega
LEAN
if lean "$d/ub.lean" 2>/dev/null; then
  echo "kernel accepted (all integers, pAB >= 0):  pA + pB - pAB <= pA + pB"
  echo "the two-set union bound; the general countable bound is the capsule's"
  echo "disjointify-then-sum argument on top of this, plus countable additivity."
else
  echo "FAIL: lean rejected union_bound"; rm -rf "$d"; exit 1
fi
rm -rf "$d"
```

### In the wild

The union bound is the **first-moment method** (Erdős): to prove an object with
no bad feature exists, bound `P(some bad feature) ≤ Σ P(bad_i) < 1` — the first
lower bounds on Ramsey numbers, and the existence of good error-correcting codes
and expander graphs. As the **Bonferroni correction** it controls the
family-wise error rate when many hypotheses are tested at once; and "n balls in
n bins, max load `O(log n / log log n)` w.h.p." — the analysis behind hash
tables and consistent hashing — is a union bound over bins.

```bash [name:app_boole_inequality, deps:chk_boole_inequality]
# Bonferroni: to keep the chance of ANY false positive below alpha across m tests,
# test each at alpha / m.  Genome-wide association studies run ~1e6 SNP tests.
alpha="0.05"; m=1000000
per_test=$(echo "scale=12; $alpha / $m" | bc -l)
echo "family-wise alpha = $alpha  across  m = $m  independent tests:"
echo "  Bonferroni per-test threshold = alpha/m = $per_test"
echo "  (this is the 5e-8 'genome-wide significance' line in GWAS)"
# and the union-bound guarantee it buys:
echo "  P(>= 1 false positive) <= m * (alpha/m) = $alpha   (union bound, any dependence)"
```

```bash [name:tight_boole_inequality, deps:chk_boole_inequality]
# the boundary case: DISJOINT events => the bound is an equality  (exact sixths)
p_a=2; p_b=2; p_c=2                              # A={1,2}, B={3,4}, C={5,6}
p_sum=$(( p_a + p_b + p_c ))
p_union=6
echo "disjoint A={1,2}, B={3,4}, C={5,6}:"
echo "  P(A)+P(B)+P(C) = $p_sum/6   ==   P(A cup B cup C) = $p_union/6"
[ "$p_sum" = "$p_union" ] || { echo "FAIL: should be equality when disjoint"; exit 1; }
```

## Capstone: from the axioms to a real bound

One die, one question: *what is the chance a single roll lands in
`A = {1,2,3}`, `B = {3,4}`, or `C = {4,5,6}`?*

```bash [name:capstone, deps:"chk_boole_inequality | cx_kolmogorov_axioms | lean_boole_inequality | app_boole_inequality"]
echo "================================================================"
echo "  Omega = {1..6},  F = 2^Omega,  P({k}) = 1/6"
echo "================================================================"
echo
echo "  Established above, in order:"
echo "    * F = 2^Omega is a sigma-algebra              [chk_sigma_algebra]"
echo "    * (Omega, F) is a measurable space            [chk_measurable_space]"
echo "    * counting/uniform P is a measure             [chk_measure]"
echo "    * P >= 0, P(Omega) = 1, countably additive    [chk_kolmogorov_axioms]"
echo "      => (Omega, F, P) is a probability space"
echo "    * finite additivity on disjoint pieces        [chk_finite_additivity]"
echo "    * monotone + subadditive                      [chk_measure_monotonicity]"
echo
echo "  The question: P(A cup B cup C) for A={1,2,3}, B={3,4}, C={4,5,6}."
# exact sixths.  singles = 3+2+3 = 8 ; pairs = |{3}|+|{4}|+0 = 2 ; triple = 0
exact=$(( (3 + 2 + 3) - (1 + 1 + 0) + 0 ))       # inclusion-exclusion  -> 6/6
boole=$(( 3 + 2 + 3 ))                           # Boole bound          -> 8/6
echo "    exact  (inclusion-exclusion) : $exact/6   (= 1)"
echo "    Boole  bound                 : $boole/6   (= 4/3)"
[ "$exact" -le "$boole" ] || { echo "FAIL: Boole bound below the true value"; exit 1; }
echo
echo "  VERDICT: three axioms + a sigma-algebra, and the union bound already"
echo "  drops out -- no random variable, no expectation, no independence needed."
echo "  Countable additivity did no work here (Omega is finite) -- but strip it"
echo "  [cx_kolmogorov_axioms] and the theory past this point collapses."
echo "  Every step above is choice_free and constructive."
echo
echo "  IN THE WILD: this exact bound, P(union) <= sum, is the first-moment method"
echo "  (existence proofs for codes and expanders), the Bonferroni correction"
echo "  [app_boole_inequality], and the balls-in-bins analysis behind hash tables."
```
