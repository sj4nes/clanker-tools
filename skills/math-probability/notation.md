# Master symbol list — Release 0.1

| Symbol | Meaning | Type / lives in | Node |
|---|---|---|---|
| `Omega` | sample space | nonempty set | `probability_space` |
| `omega` | an outcome | element of `Omega` | `probability_space` |
| `F` (script) | event sigma-algebra | subset of `2^Omega`, a sigma-algebra | `sigma_algebra` |
| `G`, `H` (script) | sub-sigma-algebras (information) | sigma-algebra `subset F` | `conditional_expectation_abstract` |
| `sigma(C)` | sigma-algebra generated by `C` | sigma-algebra | `generated_sigma_algebra` |
| `B(R)`, `B(R^d)` | Borel sigma-algebra | `sigma(open sets)` | `borel_sigma_algebra` |
| `P` | probability measure | `F -> [0,1]`, countably additive, `P(Omega)=1` | `kolmogorov_axioms` |
| `mu`, `nu` | general (sigma-finite) measures | `F -> [0, inf]` | `measure` |
| `A^c`, `A cup B`, `A cap B` | complement, union, intersection of events | elements of `F` | `set_algebra` |
| `A_n i.o.` | `limsup_n A_n` = "infinitely many `A_n` occur" | element of `F` | `limsup_liminf` |
| `1_A` | indicator of `A` | `Omega -> {0,1}`, measurable iff `A in F` | `indicator_rv` |
| `X`, `Y`, `Z` | random variables | measurable `(Omega,F) -> (R, B(R))` | `random_variable` |
| `X ~ mu` | `X` has law `mu` | — | `distribution_pushforward` |
| `P_X` | law / distribution of `X` | `P o X^{-1}`, a measure on `(R,B(R))` | `distribution_pushforward` |
| `F_X` | CDF of `X` | `F_X(x) = P(X <= x)`, nondecreasing, right-cts | `cdf` |
| `F_X^{-1}` | quantile function | generalized inverse `inf{x : F_X(x) >= u}` | `quantile_function` |
| `p_X` | pmf | `p_X(x) = P(X = x)` | `pmf` |
| `f_X` | pdf | `dP_X / d(Lebesgue)` | `pdf` |
| `E[X]` | expectation | `integral_Omega X dP`, defined for `X in L^1` or `X >= 0` | `expectation` |
| `Var(X)`, `sd(X)` | variance, standard deviation | `E[(X-EX)^2]`, `sqrt(Var)` | `variance` |
| `Cov(X,Y)`, `rho(X,Y)` | covariance, correlation | `E[XY]-EX EY`, `Cov/(sd sd)` | `covariance`, `correlation` |
| `m_k`, `mu_k` | `k`-th raw / central moment | `E[X^k]`, `E[(X-EX)^k]` | `moment` |
| `||X||_p` | `L^p` norm | `E[|X|^p]^{1/p}` | `lp_space` |
| `M_X(t)` | moment generating function | `E[e^{tX}]`, possibly `+inf` | `mgf` |
| `phi_X(t)` | characteristic function | `E[e^{itX}]`, `|phi_X| <= 1`, always exists | `characteristic_function` |
| `X ⟂ Y` | `X`, `Y` independent | generated sigma-algebras independent | `independence_random_variables` |
| `X_1,...,X_n iid` | i.i.d. sample | mutually independent, common law | `iid` |
| `X * Y`, `f_X * f_Y` | convolution (law of a sum) | measure / density | `convolution_formula` |
| `E[X \| Y = y]` | elementary conditional expectation | a number, per value `y` | `conditional_expectation_elementary` |
| `E[X \| G]` | conditional expectation given `G` | a `G`-measurable random variable, a.s. unique | `conditional_expectation_abstract` |
| `-->^{a.s.}` | almost sure convergence | mode tag | `convergence_almost_sure` |
| `-->^{p}` | convergence in probability | mode tag | `convergence_in_probability` |
| `-->^{L^p}` | convergence in `L^p` | mode tag | `convergence_in_lp` |
| `-->^{d}` | convergence in distribution | mode tag (CDF convergence at continuity points) | `convergence_in_distribution` |
| `Bin(n,p)`, `Pois(lambda)`, ... | named distribution families | — | `binomial_distribution`, `poisson_distribution`, ... |
| `N(mu, sigma^2)` | normal law, **variance** parameterisation | measure on `(R, B(R))` | `normal_distribution` |
| `Phi`, `phi` | standard-normal CDF, pdf | `R -> (0,1)`, `R -> (0, inf)` | `standard_normal` |
| `C(n,k)` | binomial coefficient | nonnegative integer | — |

Empty sum `= 0`; empty product `= 1`. `log` / `exp` are natural base.
`P(A \| B)` requires `P(B) > 0`.
