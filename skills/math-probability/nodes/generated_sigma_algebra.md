# generated_sigma_algebra

## Type
construction

## Statement
For any collection C of subsets of Omega, sigma(C) is the smallest sigma-algebra containing C -- the intersection of all sigma-algebras that contain C.

## Symbols
- `C` — a collection of subsets, type: subset of 2^Omega
- `sigma(C)` — the generated sigma-algebra, type: sigma-algebra

## Epistemic status
constructive_result

## Prerequisites (tsort edges into this node)
set_algebra, sigma_algebra

## Hypotheses
(none — unconditional within scope)

## Proof provenance
technique: intersect all sigma-algebras containing C; verify the intersection is a sigma-algebra and is contained in every other such -- hence smallest
derives_from: sigma_algebra
lean_status: cited


## Well-definedness
an arbitrary intersection of sigma-algebras on Omega is a sigma-algebra (each axiom is preserved under intersection); 2^Omega contains C, so the family intersected is nonempty.

## Type / well-formedness check
the intersection is over a nonempty family (2^Omega always qualifies), so sigma(C) exists and is itself a sigma-algebra; it is the unique smallest one.

## Specialization / boundary cases
- C = { (-inf, x] : x in Q }: sigma(C) = B(R)
- C = a single set A: sigma(C) = { empty, A, A^c, Omega }

## Common misuse
- trying to describe sigma(C)'s members explicitly -- usually impossible; work via the pi-lambda theorem instead
- confusing 'generated by' with 'the algebra generated by' (finite operations)
