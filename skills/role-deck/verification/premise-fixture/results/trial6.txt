The marker is passed as a regular expression, not a literal string. In a BRE, * is the repetition operator, and *** is an invalid repetition operand -- the grep on this machine (ugrep, and BSD grep behaves the same way) rejects the pattern outright: grep: repetition-operator operand invalid, exit status 2. A crashed grep is indistinguishable from marker not found. set -e does not save it either. Fix: grep -qF. Verified on a copy of the harness: it now prints harness: FAILED and exits 1, and grep -qF correctly returns 1 (not 2) on input without the marker.
