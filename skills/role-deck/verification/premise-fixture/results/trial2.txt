grep without -F treats the pattern as a basic regular expression, where * is the repetition operator. *** is a repetition operator with no valid preceding element, so grep never searches at all: grep: repetition-operator operand invalid, exits with status 2. Status 2 is non-zero, so the if condition reads false. set -e does not fire, because a command in an if condition is exempt from errexit. Confirmed by running the two files as-is. Fix: grep -qF '*** FAIL'. Verified: with -qF the harness prints harness: FAILED and exits 1.
