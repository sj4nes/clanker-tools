The marker is passed as a basic regular expression, not a literal string. A BRE cannot begin with * -- there is nothing for the repetition operator to repeat. grep rejects the pattern: grep: repetition-operator operand invalid, exit 2. Exit status 2 means error, not match. if tests only for zero, so a non-zero-but-not-1 status reads exactly like "no match". set -e does not rescue this either: a command in an if condition is exempt from errexit. Fix: grep -qF '*** FAIL'. Verified on a copy: the harness now prints harness: FAILED and exits 1.
