*** FAIL is passed as a basic regular expression. A leading * is not a valid BRE. Both greps on this machine reject it: BSD /usr/bin/grep says grep: repetition-operator operand invalid; ugrep, what grep resolves to interactively, says empty (sub)expression. Either way grep exits 2 (error), not 0 or 1. if treats any non-zero status as false. set -e does not save it. Fix: grep -qF '*** FAIL'. Verified: with that one-character change the harness prints harness: FAILED and exits 1.
