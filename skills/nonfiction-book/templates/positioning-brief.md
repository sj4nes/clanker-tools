# Positioning brief

One to two pages. The decision-making document for the whole project — every
later choice (a chapter, an example, a cut) is checked against it. Written before
deep research or drafting.

```yaml
positioning_brief:
  working_title: ""
  working_subtitle: ""

  one_sentence_promise: ""       # "For [specific reader], this book helps them
                                 #  [achieve outcome] by [distinct approach]."
  promise_check:
    who_is_it_for: ""            # a concrete primary reader, NOT "everyone interested in..."
    what_problem: ""             # costly | frustrating | confusing | urgent | aspirational
    what_outcome: ""             # visible change in skill / knowledge / behavior / decision quality
    unique_angle: ""             # framework | access | experience | evidence | synthesis | voice
    why_a_book: ""               # needs sustained explanation / a system / stories / reference value

  book_type: ""                  # prescriptive | explanatory | narrative | argument-driven |
                                 #   memoir | reference   (exactly one governs)
  secondary_modes: []            # modes present but subordinate
  mode_mixing_risk: ""           # e.g. "history with a self-help skeleton" — how it is avoided

  target_reader:
    description: ""
    starting_state: ""           # what they know / feel / can do now
    desired_end_state: ""        # what they will know / feel / can do after
  core_problem_and_stakes: ""

  central_thesis_or_framework: ""

  comparable_titles: []          # 3-5 here; full analysis in the comps table
  differentiation_sentence: ""   # "Existing books help readers do X; this book helps
                                 #  [this reader] achieve Y using Z, which they do not combine."

  author_credibility: ""         # why you are the person to write it

  provisional_toc: []            # chapter-level, will become the fat outline

  will_not_cover: []             # REQUIRED. Disciplined exclusion is what makes the book good.

  publishing_route: ""           # traditional (proposal) | self-publishing | undecided

  assumptions_made: []           # anything filled in without confirmation
  blocking_questions: []         # minimal questions that must be answered before Phase 2
```

## Gate to Phase 2

- [ ] The promise sentence answers all five `promise_check` questions concretely.
- [ ] `who_is_it_for` names a specific primary reader, not "everyone interested".
- [ ] Exactly one `book_type` governs; mode-mixing risk is named and addressed.
- [ ] At least three comparable titles are named.
- [ ] `will_not_cover` is non-empty.
- [ ] No `blocking_questions` remain unanswered.
