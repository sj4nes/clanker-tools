## Dimensional consistency (`validation/dimensional-checks.bc`, bc 7.0.3)

17 relations checked on the `[M L T Θ N I]` 6-tuple (electric current `I` is a
base dimension here); every check prints `0 0 0 0 0 0`:
`F = N_A e`, `Q = I t`, `Q = z F n`, `m = I t M / (z F)`, `E_spec = z F E / M`,
`ΔG = −z F E`, `E° = (RT/zF) ln K`, the Nernst `RT/zF` term, `∂E/∂T = ΔS/(zF)`,
the Butler–Volmer exponent `zFη/RT` (dimensionless), `η_ohmic = I R`, `P = I V`,
`j = I / A`, `λ° = z F u`, `E_store = c V z F E`, `P_stack = A j V`, and
`V_cell = E° + η + IR` (every term a potential).
**Dimensionless by construction** (asserted, not computed): `z`, `η_C`, `η_V`,
`η_E`, `η_F`, `t_i`, `SOC`, `K`, `Q`, `ln K`, `exp(zFη/RT)`.
**Recorded caveat:** dimensional consistency is necessary, not sufficient — it
does not fix a wrong coefficient, sign, regime, or missing term.

## Derivation-step arithmetic (`validation/derivation-checks.lean`, Lean 4.33.1, no Mathlib)

29 kernel-`decide`d instance checks over `Int` (potentials in centi- or
milli-volts, charges in coulombs, energies scaled). Grouped:
1. `faradays_law_electrolysis` — `1 F` → `1 mol` (`z = 1`); `192970 C / (2·96485)
   = 1 mol` (`z = 2`).
2. Faraday **volume ratio** — `4/2 = 2` (`H₂ : O₂`); electron balance `2·2 =
   4·1`.
3. `standard_cell_potential` — Daniell `34 − (−76) = 110` cV; vanadium `100 −
   (−26) = 126` cV.
4. `gibbs_from_cell_potential` — `ΔG = −2·96485·110`; sign flips on reversal.
5. `equilibrium_from_cell_potential` — `ln K = 212267 / 2478 = 85`.
6. `nernst_equation` — at `Q = K`, `85 − 85 = 0`; `Q < K` ⇒ `85 − 40 > 0`.
7. `nernst_298k_form` — `5916 / 1` and `5916 / 2` (the `59.16/z` mV decade).
8. `butler_volmer` / `tafel` — `1 − 1 = 0` at `η = 0`; Tafel slope `2303·2569 /
   5000 = 1183` (≈ 118.3 mV/decade).
9. `cell_voltage_electrolysis` — `123 + 10 + 30 + 35 = 198` cV; efficiency
   `148·100/198 = 74 %`.
10. `flow_battery_energy_capacity` — `1600·96485 = 154376000 C/m³`; `/3600 =
    42882 A·h`.
11. `energy_efficiency` — `97·85 = 8245` (`η_E = 82.45 %`); `< 9700` (cannot beat
    either factor).
12. `copper_electrorefining` — `34 − 34 = 0` (`E°_cell = 0`).
13. `specific_energy_consumption` charge factor — `3·96485 = 289455 C/mol Al`;
    `1000000 / 27 = 37037 mol Al per tonne`.
14. `thermodynamic_vs_kinetic_product` (chlor-alkali anode) — `123 < 136`
    (thermo favours O₂); `136 + 3 < 123 + 50` (kinetics favours Cl₂).
15. `chlor_alkali_process` — `2·1 = 1·2` (Cl₂ : H₂ = 1 : 1); `1000000 / 71 =
    14084 mol Cl₂ per tonne`.
**Recorded caveat:** Lean verified the *arithmetic* of each bookkeeping identity
only — not that `ΔG° = −RT ln K` (imported), not the Butler–Volmer rate law, and
not any tabulated `E°`, `K`, molar mass, or industrial cell figure.
