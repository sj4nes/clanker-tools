Run: `bc -q -l validation/instance-checks.bc` (or `sh build/build-tree.sh`,
which re-runs the graph checks first). Output: `build/instance-checks.out`.
A passing instance check is necessary, not sufficient — it confirms one
concrete case, not the general identity.

- Normal-Normal, `mu0=0 tau0_sq=1 sigma_sq=4 n=5 xbar=3` → posterior

All three match `results/conjugate_families.yaml`'s `specialization_cases`.

## lindleys_paradox
`n=100000, sigma_sq=1, tau0_sq=1`, `xbar` set at the `z=1.96` (`alpha=0.05`)
classical-rejection boundary. `BF_10 approx 0.0216`, i.e.
`BF_01 approx 46.3` — the diffuse-prior Bayes factor favors `H0` by about
46:1 at data a same-alpha classical test rejects. Matches
`results/lindleys_paradox.yaml`.

## credible_vs_confidence

`[9.216, 10.784]` for both the credible and confidence interval under the
flat prior. Matches `results/credible_vs_confidence.yaml`.
