# wff_syntax

## Type
definition  (epistemic status: `definition` / `notation_convention`;
`constructive_grade: intuitionistic`)

## Statement
The **well-formed formulas** (wffs) of propositional logic are the strings over
the alphabet `{atoms} ∪ {¬, ∧, ∨, →, ↔, (, )}` generated by the
`inductive_definition`:
- every atom `p` is a wff;
- `⊥` is a wff;
- if `φ` is a wff then `¬φ` is a wff;
- if `φ`, `ψ` are wffs then `(φ ∧ ψ)`, `(φ ∨ ψ)`, `(φ → ψ)`, `(φ ↔ ψ)` are
  wffs;
- nothing else is a wff.

**Notation conventions**: binding tightest→loosest `¬, ∧, ∨, →, ↔`; `→`
right-associative; outermost parentheses dropped. `↔` may be taken primitive or
defined (`biconditional_as_conjunction`); `⊥` primitive, `⊤ := (p → p)`
(`true_false_constants`).

## Symbols
- `p, q, r`: atoms (`symbol`s); `φ, ψ, χ`: schematic wffs.

## Prerequisites (tsort edges into this node)
`string`, `inductive_definition`.

## Content
The base object of the whole capsule. As an `inductive_definition` it carries
**structural induction** (`structural_induction_wff`) and **recursion**
(`recursion_on_wff`) — but only once `wff_unique_readability` is established, so
the clauses do not overlap. Every semantic and proof-theoretic notion is defined
by recursion on this grammar.

## Constructive grade
`intuitionistic` — a decidable inductive type; membership ("is this string a
wff?") is decidable by parsing.

## Lean status
`lean_status: core`. `validation/proof-checks.lean`:
```
inductive Wff where
  | atom : Nat → Wff | fls : Wff | neg : Wff → Wff
  | conj : Wff → Wff → Wff | disj : Wff → Wff → Wff | impl : Wff → Wff → Wff
```
(`↔` folded into `impl`+`conj`). Using the abstract-syntax-tree form sidesteps
the parenthesis grammar; `wff_unique_readability` is then constructor
injectivity (`conj_injective`, `conj_ne_disj`).

## Type / well-formedness check
`well_formed`. The **convention layer** matters: `p ∧ q ∨ r` is a wff **only
given** a precedence rule (else ambiguous); this capsule fixes one, so every
string either is or is not a wff, deterministically. The ABS/AST view (`Wff` as
a tree) is convention-free; the string view needs the conventions +
`wff_unique_readability` to match it.

## Specialization / boundary cases
- **Polish (prefix) notation**: `∧pq` — no parentheses, still uniquely readable.
- **atoms only**: the base case; a language with no connectives.
- **first-order**: `first_order_wff` replaces atoms by `R t₁…tₙ` / `t₁ = t₂` and
  adds `∀x`, `∃x` clauses — same inductive style.
- restricting the connective set (`{¬, →}`, `{↑}`) still generates all wffs up
  to equivalence (`functional_completeness`) but changes which strings are
  literally wffs.

## Hypothesis-dropped counterexamples
- **drop the parenthesis/precedence convention**: `p ∧ q ∨ r` has two parse
  trees — `wff_unique_readability` fails, and every recursive semantic
  definition is ill-posed.
- **drop the "nothing else" clause**: the set is not the *least* fixed point;
  structural induction fails.
- **allow infinite strings**: not wffs (finiteness is definitional; every wff
  has finitely many atoms — the basis of `tautology_decidable`).

## Common misuse
Writing an ambiguous string and assuming a parse; treating `¬¬p` as needing
parentheses; conflating the string and the parse tree; assuming a different
connective basis is a different logic (same theorems, different literal wffs);
forgetting `↔`'s status (primitive vs defined).

## Related nodes (non-prerequisite)
- `carries`: `structural_induction_wff`, `recursion_on_wff` (its induction /
  recursion principles).
- `needs`: `wff_unique_readability` (to license the above).
- `defines`: the connectives, `⊤`/`⊥` (`true_false_constants`).
- `generalised_by`: `first_order_wff`.
