# Consistency audit — Release 0.1

Run all:
`sh build/build-tree.sh && bc -q -l validation/dimensional-checks.bc && lean validation/derivation-checks.lean && sh build/gen-assumption-index.sh && sh build/gen-symbol-index.sh`

## Graph (`build/build-tree.sh`)

- 113 registered nodes, 215 prerequisite edges after `sort -u`.
- Every edge line has exactly 2 fields; no self-edges (`validation/graph-check.sh`).
- Every edge endpoint exists in `nodes/nodes.tsv` (`build/unknown-edge-nodes.txt`
  empty).
- `tsort`: empty stderr (`validation/tsort-errors.txt`), 113-node order →
  **acyclic**. BSD-safe check: stderr is inspected, not just exit status (macOS
  `tsort` exits 0 on a cycle).
- Every one of the 215 edges satisfied by `indexes/tsort-order.txt` (no
  `order violation` from the `build-tree.sh` awk pass).
- 0 isolated / root-only nodes (`build/isolated-nodes.txt` empty) — every
  registered node participates in the graph.
- Six latent cycles anticipated and pre-empted in modeling, never encoded as
  edges (`edges/cycles.md`): `equilibrium ↔ rate` (rate excluded from scope),
  `element ↔ atomic_number`, `enthalpy ↔ first law`,
  `equilibrium_constant ↔ reaction_quotient`,
  `weak_acid_equilibrium ↔ ice_table`, the `physics-thermodynamics` imports.

## Dimensional consistency (`validation/dimensional-checks.bc`, bc 7.0.3)

18 relations checked on `[M L T Θ N]` exponents; every check prints `0 0 0 0 0`
(LHS − RHS), plus one `RT c°/P°` dimensionless bookkeeping check for the Kp/Kc
factor (19 zero-tuples printed total):
`N = n N_A`, `M = m/n`, `n = m/M`, `c = n/V`, `c₁V₁ = c₂V₂`, `PV = nRT`,
`V_m = RT/P`, `Pᵢ = xᵢ P_total`, `P_total = Σ Pᵢ`, `q = mcΔT`, `c = q/(mΔT)`,
`H = U + PV`, `ΔU = q − w`, `G = H − TS`, `ΔG = ΔH − TΔS`, `ΔG° = −RT ln K`,
`ΔH_rxn = Σ n ΔH_f°`, plus the Kp/Kc factor.
**Dimensionless by construction** (asserted in comments, not computed): `K_c`,
`Q`, `K_p`, `K_w`, `K_a`, `K_a K_b`, `xᵢ`, `%X`, the pH argument, `pH + pOH`,
the Henderson–Hasselbalch log term, `k = M_molecular/M_empirical`,
`percent_yield` — each is a sum/quotient of `c/c°` or `P/P°` ratios.
**Recorded caveat:** dimensional consistency is necessary, not sufficient — it
does not fix a wrong coefficient, sign, direction, regime, or missing term.

## Derivation-step algebra (`validation/derivation-checks.lean`, Lean 4.33.1, no Mathlib)

23 kernel-`decide`d instance checks over `Int` (no Mathlib ⇒ no `ring` /
`nlinarith` over the reals, so these are instance checks at specific integer
values, not universal proofs). Grouped by identity:
1. `hess_law` — path independence `(−30) + (−70) = −100`; step reversal
   `−(−30) = 30`.
2. `enthalpy_from_formation_enthalpies` — CH₄ combustion
   `(−393 + 2(−286)) − (−75 + 0) = −890`; scaling by `k = 2`.
3. `kp_kc_relation` — `Δn` exponent bookkeeping (`2 − (1+3) = −2`); `Δn = 0 ⇒
   factor 1`; `Δn = 1` cross-multiplied instance.
4. `reaction_isotherm` / `spontaneity_criterion` — at `Q = K`, `ΔG = 0`;
   `Q < K ⇒ ΔG < 0`.
5. `ka_kb_relation` — `K_a K_b = K_w` multiplicative and `pK_a + pK_b = 14`
   log-form instances.
6. `henderson_hasselbalch` — `pH = pK_a + log([A⁻]/[HA])`; buffer centre
   `[A⁻] = [HA] ⇒ pH = pK_a`.
7. `poh_relation` — `pH + pOH = 14` instance.
8. `balancing_redox_half_reactions` — electrons lost = electrons gained
   (`5·1 = 1·5`); charge balance `(−1) + 5·2 + 8·1 = 5·3 + 2 = 17`.
9. `formal_charge` — Σ FC = species charge, CO instance.
10. `relative_atomic_mass` — abundances sum to 1 (Cl instance ×1000).
11. `molecular_formula` — `k = M_mol / M_emp` integer (glucose: `180/30 = 6`).
12. `limiting_reagent` — smallest `nᵢ/νᵢ` limits (cross-multiplied instance).
**Recorded caveat:** Lean verified the *algebra / arithmetic* of each
bookkeeping identity only — not that `H` is a state function (Hess's law), not
the ideal-gas model (Kp/Kc), not `ΔG = ΔH − TΔS` (imported from
`physics-thermodynamics`), and not any tabulated enthalpy or `K` value.
