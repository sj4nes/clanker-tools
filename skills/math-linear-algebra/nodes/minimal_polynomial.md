# minimal_polynomial

## Type
definition

## Statement
m_T is the unique MONIC generator of the ideal {p in F[t] : p(T) = 0}. It divides every annihilating polynomial (in particular p_T, by Cayley-Hamilton), and its roots are exactly the eigenvalues of T.

## Symbols
- `m_T` — type: monic element of F[t]
- `Ann(T)` — the annihilator ideal

## Type / well-formedness check
Well-formed as a definite description BECAUSE F[t] is a principal ideal domain (polynomial_ring): the annihilator is a nonzero ideal (nonzero because L(V) is finite-dimensional, so I, T, T^2, ... are dependent), hence generated by a unique monic element.

## Specialization / boundary cases
- T = lambda I: m_T = t - lambda, of degree 1, while p_T = (t - lambda)^n
- J = [[1,1],[0,1]]: m_J = (t-1)^2 = p_J
- m_T and p_T always have the SAME ROOTS, but with possibly different multiplicities

## Hypothesis-dropped counterexamples
- **finite_dimensionality**: on an infinite-dimensional space an operator need not satisfy any polynomial -- the annihilator can be {0} and there is no minimal polynomial
- **monicity_and_principality**: without the PID structure of F[t] there would be no single generator, hence no 'the' minimal polynomial

## Common misuse
- assuming m_T = p_T: equal only when T is CYCLIC (has a vector whose orbit spans), e.g. a single Jordan block
- assuming deg m_T tells you diagonalisability directly: what matters is whether m_T has REPEATED factors
